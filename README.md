## โปรแกรมในชุด / The programs

### DriveVault Master Pro
ศูนย์กลางของชุดโปรแกรม: แสดงโปรแกรมที่ติดตั้ง เปิด ติดตั้ง อัปเดต และถอนการติดตั้งจากที่เดียว และมี **เอไอที่รันบนเครื่องของคุณเอง** อีกสองหน้า
*The hub of the suite: shows, opens, installs, updates and uninstalls the programs - and has two pages of an **AI that runs on your own PC**.*

- **โปรแกรม / Programs** - ค้นหาและกรองตามหมวด มีปุ่ม **ตรวจหาอัปเดต** อยู่ในช่องค้นหา ตรวจเวอร์ชันใหม่ให้เมื่อเปิดโปรแกรม (ปิดได้) และอัปเดตตัวเองได้ - จะดาวน์โหลดก็ต่อเมื่อคุณกดปุ่มอัปเดต
- **เอไอถามตอบ / AI Q&A** - ถามตอบด้วยโมเดลภาษาที่รันในเครื่อง รู้จักโปรแกรมในชุด DriveVault ค้นเว็บเพิ่มได้เมื่อคุณอนุญาต *(a chat with a language model on your PC; it can search the web when you allow it)*
- **เอเจนติกเอไอ / Agentic AI** - เอไอที่ทำงานกับไฟล์ในโฟลเดอร์ที่คุณเลือก: ดูรายการไฟล์ อ่าน ค้นหา และแก้ไฟล์ได้ตาม **โหมด** ที่เลือก - *อ่านอย่างเดียว*, *แผน* (เขียนแผนงาน ไม่แก้อะไรจนกว่าคุณจะอนุมัติแผน), *ถามก่อน* (ทุกการแก้ไฟล์และทุกคำสั่งต้องรอให้คุณกดอนุญาต) หรือ *ยอมรับการแก้ไข* (แก้ไฟล์ได้เลย แต่รันคำสั่งยังถามเสมอ) ไฟล์ที่ถูกแก้จะถูกเก็บฉบับเก่าไว้ก่อน มีรายการงานสำหรับงานใหญ่ อ่านไฟล์ CLAUDE.md ของโฟลเดอร์ และมีคำสั่ง `/help` `/mode` `/clear` เอไอรันคำสั่ง (cmd.exe) ได้ต่อเมื่อคุณกดอนุญาตทีละคำสั่ง คำสั่งรันด้วยสิทธิ์ของคุณและไม่จำกัดแค่ในโฟลเดอร์ และเอไอไม่ลบไฟล์เอง *(works in a folder you choose; modes: read only, plan, ask first, accept edits; it edits files, keeps a task list, reads the folder's CLAUDE.md and can run a command only after you allow that command)*
- **เลือกโมเดลและระดับความพยายามได้ในแชต / Model and effort in the chat** - ระดับ *เร็ว* / *ปกติ* / *ลึก* (ลึก = ให้โมเดลคิดก่อนตอบ ช้าลงราว 3 เท่า)
- **โมเดล / Models** - ตัวติดตั้งดาวน์โหลด Qwen3.5-4B ให้ (ประมาณ 2.7 GB เลือกไม่โหลดได้) ในตั้งค่า AI โหลดโมเดลอื่นจากรายการ (Qwen3.5 ขนาด 0.8B / 2B / 4B / 9B และ Typhoon 2.5 ที่เน้นภาษาไทย) หรือวางลิงก์ไฟล์ `.gguf` จาก Hugging Face ทุกไฟล์ถูกตรวจขนาดและ SHA-256 ก่อนใช้ *(a model is downloaded by the installer unless you clear that task; more in the AI settings)*
- **ไม่ใช้บริการ AI ออนไลน์ / No online AI service** - ไม่มี API key ไม่ต้องสมัครสมาชิก คำถาม ไฟล์ และบทสนทนาอยู่ในเครื่องคุณ ข้อจำกัด: โมเดลขนาดเล็กบนโน้ตบุ๊กตอบได้ดีเท่าที่ขนาดของมันอำนวย และคำตอบอาจผิดได้ ควรตรวจก่อนใช้

### DriveVault Video Editor Pro
โปรแกรมตัดต่อวิดีโอแบบหลายแทร็ก ใช้งานได้ทั้งภาษาไทยและอังกฤษ
*A multi-track video editor, with a Thai and English interface.*

- **ตัดต่อ / Editing** - ไทม์ไลน์หลายแทร็ก (เพิ่ม ลบ เปลี่ยนชื่อ ย่อขยายแทร็กได้), ตัด แยก ย้าย, เครื่องมือ ripple / roll / slip / slide, undo ทุกขั้นตอน, คีย์เฟรม
- **ภาพ / Picture** - ย้าย ย่อขยาย หมุนคลิปบนภาพตัวอย่างโดยตรง, ทรานซิชัน, เอฟเฟกต์ (เบลอ คมชัด ขอบมืด ครอป), ฟิลเตอร์สีและการปรับสี (รวมถึงเส้นโค้งสีและไฟล์ LUT), ชื่อเรื่อง แถบชื่อ และคำบรรยาย
- **เสียง / Audio** - มิกเซอร์แต่ละแทร็ก, มาสเตอร์เสียงแสดงตลอด, ปรับระดับเสียงที่เส้นบนคลิป, ลดเสียงรบกวน
- **AI แบบออฟไลน์ (เลือกเปิดเอง) / Optional offline AI** - ถอดเสียงเป็นซับอัตโนมัติ (ภาษาไทยด้วยโมเดล OpenThai 2.0 ที่รันในเครื่อง ภาษาอื่นด้วย whisper.cpp), ตรวจช่วงเงียบ, แนะนำจุดตัด, ติดตามวัตถุ ทำงานบนเครื่องของคุณทั้งหมด ตัวติดตั้งดาวน์โหลดโมเดลเสียงให้ (เลือกไม่โหลดได้) หรือกดโหลดเองทีหลังในตั้งค่า คำบรรยายที่ได้อาจผิด ควรตรวจ
- **ให้ผู้ช่วย AI บนเครื่องช่วยตัดต่อ (MCP) / Let an AI assistant work on the project** - เปิดเองในตั้งค่า > AI (ปิดไว้เป็นค่าเริ่มต้น) โปรแกรมผู้ช่วยบนเครื่องเดียวกัน เช่น Claude Code หรือ Codex เชื่อมเข้ามาจัดการโปรเจกต์ที่เปิดอยู่ได้ (ดู นำเข้า วาง ตัด ย้าย ลบ ใส่ซับ ย้อนกลับ) ทุกการแก้เป็น undo หนึ่งขั้น มีเมาส์เสมือนขึ้นบอกว่ากำลังทำอะไร รับเฉพาะการเชื่อมจากเครื่องนี้ ต้องมีโทเคนส่วนตัว และสั่งรันโปรแกรมหรือลบไฟล์ไม่ได้
- **ส่งออก / Export** - MP4, MOV, MKV (H.264 + AAC) พร้อมค่าสำเร็จรูป ตรวจไฟล์ที่ส่งออกให้อัตโนมัติ
- **โปรเจกต์ / Projects** - สื่อที่นำเข้าถูกคัดลอกเก็บไว้ในโฟลเดอร์โปรเจกต์ ย้ายต้นฉบับก็ไม่พัง บันทึกอัตโนมัติและกู้คืนได้

### DriveVault PDF Pro
โปรแกรมจัดการไฟล์ PDF ทำงานบนเครื่องของคุณทั้งหมด ไม่อัปโหลดไฟล์ไปที่ใด ใช้งานได้ทั้งภาษาไทยและอังกฤษ
*A PDF program that works on your computer only - nothing is uploaded. Thai and English interface.*

- **อ่านและค้นหา / Read and search** - เปิดหลายไฟล์เป็นแท็บ, ค้นหาทั้งไฟล์, เลือกและคัดลอกข้อความ, บุ๊กมาร์ก, ซูมพิมพ์เอง, มือจับเลื่อน, ถ่ายภาพบริเวณหน้า, อ่านออกเสียงด้วยเสียงของ Windows *(multi-tab reader, find, copy text, bookmarks, typed zoom, hand tool, snapshot, read aloud)*
- **ผู้ช่วย AI ถามตอบและสรุปเอกสาร / AI assistant** - แท็บ "AI" ในแผงด้านข้างตอบคำถามเกี่ยวกับเอกสารที่เปิดอยู่และสรุปให้ ระบุหน้าที่คำตอบมาจาก ด้วยโมเดลที่รันในเครื่อง (Qwen3.5-4B) ผู้ช่วยอ่านอย่างเดียว ไม่แก้เอกสาร ตัวติดตั้งดาวน์โหลดโมเดลให้ (ประมาณ 2.7 GB เลือกไม่โหลดได้) หรือกดโหลดเองในแผง คำตอบอาจผิด ควรตรวจหน้าที่อ้างถึง *(answers and summaries of the open document with the pages named; read only; runs on your PC)*
- **จัดการหน้า / Pages** - เรียง ลบ ทำซ้ำ หมุน ครอป แทรกหน้าว่าง รวมไฟล์ แยกไฟล์ บีบอัด *(organize, merge, split, compress)*
- **แก้ไข / Edit** - ใส่ข้อความ (ไทยและอังกฤษ) รูป รูปร่าง ปากกา ไฮไลต์ ตราประทับ โน้ต ลายน้ำ เลขหน้า เลข Bates แก้ข้อความเดิมบางส่วน และบันทึกไฮไลต์/โน้ตเป็นคอมเมนต์ PDF จริงได้ *(add text, pictures, shapes, markup, watermark, Bates numbers; markup can be saved as real PDF comments)*
- **ฟอร์ม / Forms** - กรอกฟอร์ม สร้างช่องกรอกข้อความ ช่องติ๊ก รายการเลือก ส่งออกและนำเข้าข้อมูลฟอร์ม (XFDF) *(fill, create fields, export / import form data)*
- **ความปลอดภัย / Security** - ป้องกันด้วยรหัสผ่าน (AES-256), ลบข้อมูลสำคัญแบบ redact และตรวจผล, ลงนามสำเนาด้วยใบรับรองของคุณและตรวจลายเซ็น, ตรวจการเข้าถึงเบื้องต้น *(passwords, verified redaction, signing a copy with your certificate, signature check, quick accessibility check)*
- **แปลงและชุดงาน / Convert and batch** - OCR ภาษาไทยในเครื่อง (โมเดล OpenThai 2.0 OCR Text ขนาด 4 MB อยู่ในตัวติดตั้ง), ส่งออกเป็นรูป, สร้าง PDF จากรูป, สร้าง PDF portfolio, เปรียบเทียบสองไฟล์, ชุดงานทั้งโฟลเดอร์ *(local Thai OCR, export images, create PDF, portfolio, compare, batch)*

โปรแกรมไม่แก้ไฟล์ต้นฉบับ - ทุกอย่างบันทึกเป็นสำเนาใหม่ ยังไม่มี: การลงนามแบบมองเห็น, การใส่แท็ก PDF/UA, PDF/A, การแก้ย่อหน้าเดิมให้ไหลต่อกัน
*It never changes the original - everything is saved as a new copy. Not available yet: visible signatures, PDF/UA tagging, PDF/A, re-flowing existing paragraphs.*

## ติดตั้ง / Install

1. ดาวน์โหลดไฟล์ `...Setup-x64.exe` จากตารางด้านบน แล้วดับเบิลคลิก *(download the setup file above and run it)*
2. **Windows อาจขึ้นหน้าเตือนสีน้ำเงิน "Windows protected your PC"** เพราะตัวติดตั้งยังไม่ได้เซ็นลายเซ็นดิจิทัล (ต้องซื้อใบรับรอง) ให้กด **More info** แล้วกด **Run anyway**
   *Windows may show a blue "Windows protected your PC" window because the installer is not digitally signed yet. Choose **More info**, then **Run anyway**.*
3. ทำตามขั้นตอนของตัวติดตั้ง (ไทย/อังกฤษ) โปรแกรมจะอยู่ใน `C:\Program Files\DriveVault` *(follow the wizard)*

**ตรวจว่าไฟล์ไม่เสียหาย (ไม่บังคับ) / Check the download (optional):** เปิด PowerShell ในโฟลเดอร์ที่ดาวน์โหลด แล้วเทียบผลกับไฟล์ `.sha256` ที่อยู่ใน Release เดียวกัน
*Open PowerShell where you saved the file and compare the result with the `.sha256` file of the same release.*

```powershell
Get-FileHash .\DriveVault-Video-Editor-Pro-Setup-x64.exe -Algorithm SHA256
```

## อัปเดต / Updating

เปิด **DriveVault Master Pro** แล้วกด **ตรวจหาอัปเดต** (หรือรอให้ตรวจเองตอนเปิดโปรแกรม) ถ้ามีรุ่นใหม่จะมีปุ่มดาวน์โหลดและอัปเดต ไฟล์ที่ดาวน์โหลดถูกตรวจค่า SHA-256 ก่อนเปิดทุกครั้ง
*Open Master Pro and press "Check for updates". A new version gets a download-and-update button; every download is checked against its SHA-256 before it runs.*


## ความเป็นส่วนตัว / Privacy

โปรแกรมทำงานบนเครื่องของคุณ ไม่เก็บข้อมูลการใช้งาน ไม่ส่งไฟล์ของคุณไปที่ไหน เอไอทุกตัวรันในเครื่อง ไม่มีบริการ AI ออนไลน์ ใช้อินเทอร์เน็ตเฉพาะกรณีต่อไปนี้ และทุกกรณีเกิดจากสิ่งที่คุณสั่งหรือเลือกไว้:
- Master Pro ตรวจหาอัปเดตจาก GitHub (ปิดการตรวจตอนเปิดโปรแกรมได้) และดาวน์โหลดเมื่อคุณกดปุ่มอัปเดต
- ดาวน์โหลดโมเดล AI จาก Hugging Face - ตอนติดตั้ง (เป็นงานที่เลือกไม่ทำได้) หรือเมื่อคุณกดปุ่มดาวน์โหลดเอง ไฟล์ถูกตรวจ SHA-256 ก่อนใช้ ติดตั้งแบบเงียบไม่ดาวน์โหลดอะไรเลย
- เอไอใน Master Pro ค้นเว็บ (DuckDuckGo) และเปิดหน้าเว็บอ่านเมื่อสวิตช์ "เว็บ" เปิดอยู่ (เปิดเป็นค่าเริ่มต้น ปิดได้ที่ใต้ช่องพิมพ์หรือในตั้งค่า AI) ส่งออกไปเฉพาะคำค้นและที่อยู่หน้าเว็บ ไม่ส่งไฟล์หรือบทสนทนา

*The programs work on your PC, collect no usage data and never upload your files. Every AI runs on your PC; there is no online AI service. The internet is used only for: Master Pro checking GitHub for updates (and downloading when you press the update button); downloading AI models from Hugging Face - during setup (a task you can clear) or when you press a download button, checked against a SHA-256 first, and never during a silent install; and the AI of Master Pro searching the web (DuckDuckGo) and reading a page while the "Web" switch is on (on by default, switch it off under the message box or in the AI settings) - only the search words and the address of a page go out, never your files or the conversation.*
