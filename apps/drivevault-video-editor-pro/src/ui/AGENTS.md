# drivevault-video-editor-pro/src/ui - rules (adds to the parent files)

- QML module `DriveVault.UI` (static); backend objects come from `DriveVault.Backend` as singletons: `AppSettings, Localization, Recents, Projects, App, SysInfo, WinIntegration, Playback, ExportJob, Ai, Proxies`.
  Every new `.qml` file must be listed in `ui/CMakeLists.txt`; `Theme.qml` is a singleton.
- Design system: `docs/ui-design-system.md`. Use `Theme` tokens (colours, radii, font sizes, durations), the shared components in `components/` (`AppButton`, `IconButton`, `AppSlider`, `AppMenu` ...) and icons from `IconData.js`. No hard-coded colours except brand / clip colours defined in `Theme`.
- Use `AppText` (components/AppText.qml), never plain `Text`: it gives every line the height of a Thai line (`ThaiMetrics`), so Thai and English lay out the same; Theme font sizes are the same for both languages. Exception: `AppToolTip` (a fixed line height there makes the popup polish in a loop). Do not name a singleton like a QtQuick type (`TextMetrics` is taken).
- Texts: `qsTr` only. Use `%n` plural forms for counts. Thai text is rendered with Noto Sans Thai.
- Folders: `screens/` (Home, New project, dialogs), `editor/` (Edit screen, timeline, inspector, AI panel, export workspace, workspace bar, menus), `settings/` (pages), `components/`.
- Navigation rule: the bar at the top (`WorkspaceBar`) holds only the workspaces Home / Edit / Color / Export; everything that is a tool tab (Import, Audio, Text, Effects, Transitions, Filters, Adjustment, AI) lives in the tool panel and shows its content **in that panel**, never in the inspector. Do not add a second button for the same thing.
- The top-left panel is `editor/ToolPanel.qml` (tabs Import / Audio / Text / Effects / Transitions / Filters / Adjustment / AI; the Import tab holds `MediaPanel`). Its tiles must call real `Projects.timeline` operations (never placeholders); looks and effects are made of real parameters (`applyParams`, `mix`). `editor/MasterMeter.qml` is the always-visible master meter at the right of the timeline (`meterL` / `meterR`). Objectnames `toolTab_<key>`, `look_*`, `fx_*`, `trIn_*` / `trOut_*`, `text_*` are used by `tst_ui_flow`.
- The bottom panel has two tabs, Timeline and Mixer (`EditorScreen.qml`, `MixerPanel.qml`, `MixerKnob.qml`, `MixerFader.qml`): strips per audio track, left aligned (track gain fader, High / Mid / Low EQ, pan, solo / mute: all belong to the track and are saved in the project) and the master fader (`Projects.masterGainDb`, saved in the project, used by preview and export). The AI tab is an accordion (`ParamSection.controlled`). Never name an id `scale` (it shadows `Item.scale`).
- Inspector sections are `ParamSection` + `ParamRow`s bound to `Projects.timeline.paramValue(...)`; refresh them through the `rev` counter, not by polling. Workspaces decide which sections show (see `InspectorPanel.qml`).
- Rules that bit before: no property named `onXxx`, `clip`, `layer`; an outer id is shadowed inside delegates; `Layout.minimumWidth: 0` on sections; do not assign `undefined` to typed properties (give `info` objects defaults); `required property` in delegates.
- Keep `objectName`s stable (`tst_ui_flow` clicks them): e.g. `trackSolo<N>`, `tool_<name>`, `preset_<id>`, `aiSilence`, `exportStart`, `param_<key>`, `key_<key>`.
- Never block the UI: long actions call backend jobs that report progress and can be cancelled.
- Status badges tell the truth: `available`, `modelRequired`, `unsupported`, `notImplemented`, `info`.
- `tst_ui_flow` fails on any QML warning - run it after UI changes and fix every warning.
- The window is frameless (`flags: Qt.Window | Qt.FramelessWindowHint` in `Main.qml`) with our own `components/TitleBar.qml` (brand, Thai / English switch, "..." menu with Settings and About, `WindowButton`s) - the same bar as Master Pro and PDF Pro; the `ResizeEdge` strips at the end of `Main.qml` start the system resize. Screens sit below `titleBar` (anchor to `titleBar.bottom`, never `fill: parent`). `WinIntegration.applyTitleBarTheme` is no longer called (there is no Windows caption to tint).
