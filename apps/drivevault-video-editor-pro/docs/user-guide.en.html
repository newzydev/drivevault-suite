Getting started

Windows warning when installing: the installer is not digitally signed yet, so Windows may show "Windows protected your PC". Choose More info and then Run anyway. This only means the publisher is not yet known to Windows.
  1. On the Home screen choose New Project, name it and pick the resolution and frame rate. The project is a folder with one .dvproj file; your media stay where they are.
  2. Import media with Ctrl+I or drag files from Explorer into the window (MP4, MOV, MKV, AVI, WebM, MP3, WAV, AAC, FLAC, PNG, JPG, WebP).
  3. Double-click a media item (or drag it) to put it on the timeline.
  4. Edit, then open the Export workspace (Ctrl+M).

The bar under the menu switches between Home, Edit, Color and Export. The tool panel at the top left has the tabs Import, Audio, Text, Effects, Transitions, Filters, Adjustment and AI; each tab shows its content in that panel.

Editing the timeline

  • Move a clip by dragging it (snapping can be switched off with the magnet button). Trim by dragging its edges. Split at the playhead with Ctrl+K.
  • Video and its audio are linked and move together. Ctrl+G groups several clips.
  • Tools: V select, B ripple trim, N roll edit, Y slip, U slide.
  • Markers: M adds one at the playhead; right-click a marker in the ruler to rename or delete it. I / O set the In / Out range used by Export.
  • Tracks: the + button adds video, audio or subtitle tracks (right-click a track to remove an empty one).
  • Everything can be undone with Ctrl+Z; the project is saved with Ctrl+S and auto-saved in the background.

Colour, effects, transitions, keyframes

Select a clip and use the Inspector: Transform (opacity, position, scale, rotation), Colour (exposure, contrast, saturation, temperature, tint, .cube look), Lift/Gamma/Gain, Curves, Effects (blur, sharpen, vignette, crop) and Transitions (cross dissolve, dip, fade, wipe, slide, zoom).

The small diamond next to a value adds a keyframe at the playhead; right-click it to choose linear, ease or hold interpolation.

Audio

Per-clip volume, bass / mid / treble, noise gate and fades are in the Inspector. The Audio mixer section has a fader, pan, solo and mute for every audio track and level meters for the master output.

Titles and subtitles

Use the + menu above the timeline to add a title, lower third, caption or subtitle. Select it to edit the text, font, colour, outline, shadow and position. Thai and English text are supported. Subtitles can be imported from and exported to .srt.

Export

Choose a preset (YouTube 1080p / 4K, Instagram / TikTok, Web 720p, Archive, Audio only) or set format, resolution, quality and encoder yourself. You can export the whole sequence or only the In-to-Out range, a single frame as PNG, or the sound only (M4A). The finished file is checked automatically (size, frame rate, duration, audio, picture). Save your own presets with Save current.

AI tools (optional, offline)

Open the AI tab of the tool panel (top left) and switch the tools on. Nothing is sent to the cloud.

  • Auto captions (whisper.cpp): needs a speech model. Press Download in the model manager (the only time the program uses the internet, and only when you press it) or import a ggml-*.bin file. Then choose the language and Transcribe timeline. Check the text: automatic captions are not always accurate, especially with noise, music and names.
  • Silence detection highlights quiet passages on the timeline; Remove all cuts them out of every track (undoable).
  • Smart cut suggestions mark scene changes and pauses; nothing is cut until you press Split.
  • Audio enhancement reduces steady background noise (signal processing, not a neural network) in a copy of the audio.
  • Object tracking follows a rectangle; use it to stabilise a clip or make another clip follow the subject.
  • Assistant: type a request such as "create Thai subtitles" or "find the silent parts". It understands a fixed set of phrases, not free conversation.

Performance

Settings → Performance: preview quality (Full / Half / Quarter), the frame-cache memory limit, and proxies - small stand-ins for large videos that make the preview smooth (create them from the Inspector or the Performance page; export always uses your original files). GPU video decoding is experimental and off by default.

Where things are, and troubleshooting

ProjectsDocuments\DriveVault Projects
ExportsVideos\DriveVault Exports
  • A clip shows a red "missing" mark: the media file moved. Select it in the media panel and relink it (single file or search a folder).
  • Preview stutters: lower the preview quality, or create proxies for large videos.
  • Captions say "Model required": download or import a speech model in the AI tab.
  • Something went wrong: Help → Open Log Folder shows the log files.
  • Uninstall: Windows Settings → Apps. Your projects and exports are never deleted; the uninstaller asks before removing settings and cache.
