DriveVault Video Editor Pro

คู่มือการใช้งาน - เวอร์ชัน 1.0.1 - English

เริ่มต้นการตัดต่อสีและเอฟเฟกต์เสียงชื่อเรื่องส่งออกเครื่องมือ AIประสิทธิภาพคีย์ลัดแก้ปัญหา

เริ่มต้นใช้งาน

คำเตือนของ Windows ตอนติดตั้ง: ตัวติดตั้งยังไม่ได้เซ็นลายเซ็นดิจิทัล Windows จึงอาจแสดง "Windows protected your PC" ให้เลือก More info แล้วกด Run anyway ซึ่งหมายความเพียงว่า Windows ยังไม่รู้จักผู้เผยแพร่
  1. ที่หน้าแรกเลือก โปรเจกต์ใหม่ ตั้งชื่อ และเลือกความละเอียดกับเฟรมเรต โปรเจกต์คือโฟลเดอร์ที่มีไฟล์ .dvproj หนึ่งไฟล์ ส่วนไฟล์สื่อยังอยู่ที่เดิม
  2. นำเข้าสื่อ ด้วย Ctrl+I หรือลากไฟล์จาก Explorer เข้าหน้าต่าง (MP4, MOV, MKV, AVI, WebM, MP3, WAV, AAC, FLAC, PNG, JPG, WebP)
  3. ดับเบิลคลิกสื่อ (หรือลาก) เพื่อวางลงไทม์ไลน์
  4. ตัดต่อ แล้วเปิดพื้นที่ทำงาน ส่งออก (Ctrl+M)

แท็บพื้นที่ทำงานใต้เมนูเปลี่ยนเฉพาะแผงที่เน้น: สื่อ ตัดต่อ สี เสียง เอฟเฟกต์ AI ส่งออก

การตัดต่อบนไทม์ไลน์

  • ย้ายคลิปโดยลาก (ปิดการดูดติดด้วยปุ่มแม่เหล็ก) ตัดหัวท้ายโดยลากขอบ แบ่งคลิปที่เพลย์เฮดด้วย Ctrl+K
  • วิดีโอกับเสียงของมันถูกผูกกันและเคลื่อนไปด้วยกัน Ctrl+G จัดกลุ่มหลายคลิป
  • เครื่องมือ: V เลือก, B ตัดแบบริปเปิล, N ม้วนจุดตัด, Y สลิป, U สไลด์
  • มาร์กเกอร์: M เพิ่มที่เพลย์เฮด คลิกขวาที่มาร์กเกอร์บนไม้บรรทัดเพื่อเปลี่ยนชื่อหรือลบ I / O กำหนดช่วงเริ่ม/จบที่ใช้ตอนส่งออก
  • แทร็ก: ปุ่ม + เพิ่มแทร็กวิดีโอ เสียง หรือซับไตเติล (คลิกขวาที่แทร็กเพื่อลบแทร็กที่ว่าง)
  • เลิกทำได้ทุกอย่างด้วย Ctrl+Z บันทึกด้วย Ctrl+S และมีการบันทึกอัตโนมัติเบื้องหลัง

สี เอฟเฟกต์ ทรานซิชัน คีย์เฟรม

เลือกคลิปแล้วใช้ อินสเปกเตอร์: การแปลง (ความทึบ ตำแหน่ง ขนาด การหมุน), สี (การรับแสง คอนทราสต์ ความอิ่มตัว อุณหภูมิ โทน ลุค .cube), Lift/Gamma/Gain, เส้นโค้ง, เอฟเฟกต์ (เบลอ ความคมชัด ขอบมืด ครอบ) และทรานซิชัน (ครอสดิสโซลฟ์ จางผ่านดำ เฟด ปัด เลื่อน ซูม)

เพชรเล็กๆ ข้างค่าคือคีย์เฟรม กดเพื่อเพิ่ม/ลบที่เพลย์เฮด คลิกขวาเพื่อเลือกการประมาณค่าแบบเชิงเส้น นุ่มนวล หรือคงค่า

เสียง

ระดับเสียงต่อคลิป เสียงทุ้ม/กลาง/แหลม นอยส์เกต และเฟดอยู่ในอินสเปกเตอร์ ส่วน มิกเซอร์เสียง มีเฟเดอร์ ซ้าย-ขวา เดี่ยว และปิดเสียงของทุกแทร็กเสียง พร้อมมิเตอร์ระดับเสียงรวม

ชื่อเรื่องและซับไตเติล

ใช้เมนู + เหนือไทม์ไลน์เพื่อเพิ่มชื่อเรื่อง แถบชื่อล่าง คำบรรยาย หรือซับไตเติล เลือกแล้วแก้ข้อความ ฟอนต์ สี เส้นขอบ เงา และตำแหน่งได้ รองรับภาษาไทยและอังกฤษ นำเข้า/ส่งออกซับเป็น .srt ได้

ส่งออก

เลือกพรีเซ็ต (YouTube 1080p / 4K, Instagram / TikTok, เว็บ 720p, เก็บถาวร, เฉพาะเสียง) หรือกำหนดรูปแบบ ความละเอียด คุณภาพ และตัวเข้ารหัสเอง ส่งออกได้ทั้งซีเควนซ์ เฉพาะช่วงเริ่ม-จบ เฟรมเดียวเป็น PNG หรือเฉพาะเสียง (M4A) โปรแกรมตรวจไฟล์ที่ได้อัตโนมัติ (ขนาด เฟรมเรต ความยาว เสียง ภาพ) บันทึกพรีเซ็ตของคุณด้วย บันทึกค่าปัจจุบัน

เครื่องมือ AI (ไม่บังคับ ทำงานออฟไลน์)

เปิดพื้นที่ทำงาน AI แล้วเปิดสวิตช์ ไม่มีข้อมูลถูกส่งไปคลาวด์

  • ซับอัตโนมัติ (whisper.cpp): ต้องมีโมเดลเสียง กด ดาวน์โหลด ในตัวจัดการโมเดล (ครั้งเดียวที่โปรแกรมใช้อินเทอร์เน็ต และเมื่อคุณกดเท่านั้น) หรือนำเข้าไฟล์ ggml-*.bin แล้วเลือกภาษาและ ถอดเสียงไทม์ไลน์ ตรวจข้อความทุกครั้ง: ซับอัตโนมัติอาจไม่แม่นยำ โดยเฉพาะเมื่อมีเสียงรบกวน เพลง หรือชื่อเฉพาะ
  • ตรวจจับความเงียบ ไฮไลต์ช่วงเงียบบนไทม์ไลน์ ลบทั้งหมด จะตัดออกจากทุกแทร็ก (เลิกทำได้)
  • แนะนำจุดตัด ทำเครื่องหมายการเปลี่ยนฉากและช่วงหยุด ไม่มีอะไรถูกตัดจนกว่าคุณจะกดแบ่ง
  • ปรับปรุงเสียง ลดเสียงรบกวนคงที่ (การประมวลผลสัญญาณ ไม่ใช่โครงข่ายประสาท) ในสำเนาของเสียง
  • ติดตามวัตถุ ตามกรอบสี่เหลี่ยม ใช้ทำให้คลิปนิ่ง หรือให้อีกคลิปตามวัตถุ
  • ผู้ช่วย: พิมพ์คำขอ เช่น "สร้างซับไทย" หรือ "หาช่วงที่เงียบ" เข้าใจเฉพาะชุดวลีที่กำหนด ไม่ใช่การสนทนาอิสระ

ประสิทธิภาพ

ตั้งค่า → ประสิทธิภาพ: คุณภาพพรีวิว (เต็ม/ครึ่ง/หนึ่งในสี่) ขีดจำกัดหน่วยความจำของแคชเฟรม และพร็อกซี - ไฟล์ตัวแทนขนาดเล็กของวิดีโอใหญ่ที่ทำให้พรีวิวลื่น (สร้างจากอินสเปกเตอร์หรือหน้าประสิทธิภาพ การส่งออกใช้ไฟล์ต้นฉบับเสมอ) การถอดรหัสวิดีโอด้วย GPU เป็นโหมดทดลองและปิดไว้เป็นค่าเริ่มต้น
