# Third-party components and licenses

Status: **Phase 6 audit.** The notices shipped with the program are `THIRD-PARTY-NOTICES.txt` (human readable) and `dependency-manifest.json` (every file with owner, license and SHA-256, generated by `scripts\license-audit.ps1`, which also fails the build when FFmpeg is not LGPL-only, a GPL-only Qt module is present or a file has no owner). Open: the GPL v3 text referenced by the LGPL is linked, not bundled; the FFmpeg library list must be re-verified on every FFmpeg update; patent licensing of H.264 / AAC is the distributor's responsibility. A full license audit (including legal review) is a Phase 6 task.
Nothing below is legal advice.

### Video codecs and patents

The exporter writes **H.264 + AAC**. Which H.264 encoder runs depends on the machine: NVIDIA NVENC, Intel Quick
Sync, AMD AMF (GPU drivers), **Windows Media Foundation** (part of Windows) or OpenH264. No H.264 encoder code is
shipped by DriveVault itself except the optional OpenH264 *wrapper* inside FFmpeg; the MF / NVENC / QSV / AMF paths
use encoders that belong to the OS or the GPU driver. Distributing an H.264/AAC *encoder* and decoding H.264 may
require patent licenses in some jurisdictions (MPEG LA / Via LA) - a Phase 6 legal item.
The native FFmpeg **AAC** encoder is used for audio (LGPL).
