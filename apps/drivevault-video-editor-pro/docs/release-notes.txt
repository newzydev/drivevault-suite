DriveVault Video Editor Pro - Release notes
==========================================

Version 1.7.0
-------------
  - Bigger catalogs, grouped like a mobile editor: Text 16 styles (Title, Lower third, Caption, Subtitle, Outline, Impact, Neon, Gold, Elegant, Handwriting,
    Typewriter ...), Effects 20 (blur and sharpen levels, vignettes, Dream, Focus, letterbox / cinema bars, zoom, tilt ...), Transitions 15 in / 7 out (wipe and slide
    in four directions, zoom in / out, spin, flash ...) and Filters 24 (Basic, Film, Mood). Every tile sets real clip parameters or a real transition; the
    renderer was extended, so preview and export show the same transitions. The text fonts Impact, Georgia, Segoe Script and Consolas are Windows fonts; Thai
    letters that these fonts lack are drawn with a fallback font.
  - The bottom panel has two tabs: Timeline and Mixer. The mixer has a channel strip for every audio track (fader, pan, solo, mute and the Gain / High / Mid / Low
    knobs of the clip under the playhead on that track) and a master fader at the right, next to the always-visible master meter. The master fader is a real
    project setting (saved in the project file, used by preview and export; projects from older versions open with 0 dB). The EQ and Gain knobs edit the clip under
    the playhead because the EQ belongs to clips, not to tracks.
  - Long values in the inspector (such as the project path) are cut with "..." and the full text is the tooltip.
  - The Audio tab of the tool panel now has Import audio, Add audio track and Open mixer (the strips moved to the mixer).

Version 1.6.0
-------------
  - The Effects, Transitions and Filters tabs show every tile on a drawn sample picture (a landscape, so no media file is needed) with the effect, the look or the
    transition applied; the preview plays when the mouse is over the tile and returns to the resting picture afterwards. Clicking a tile still applies the real
    effect / transition / look to the selected clip. The previews are an approximation drawn for the tile (the exported picture is made by the real renderer).
    Blur uses the graphics card; on a PC without one the blur tiles show the sample unblurred.

Version 1.5.0
-------------
  - Program monitor: click the picture to select the clip under the pointer (a click on an empty part clears the selection). A frame appears around the clip:
    drag inside it to move (snaps to the centre), drag a corner to scale, drag the round handle above it to rotate (snaps every 45 degrees). The values are the
    clip's Position, Scale and Rotation, so everything is undoable and is exported as shown. The frame is hidden while playing.

Version 1.4.0
-------------
  - Imported media are copied into a "medias" folder next to the project file (Settings > Editing > "Copy imported media into the project", on by default).
    The copy runs in the background, the original stays where it is, the same file is not copied twice, a file with the same name from another folder gets
    "(2)" and a file that cannot be read leaves no copy. Projects that already exist keep using their files where they are.
  - Tracks can be collapsed and expanded: the arrow in the track header, or right-click > Compact track / Normal height / Tall track. The height is saved
    with the project (older projects open with normal lanes).
  - Level line on every clip: move the mouse over a clip and a line appears; drag it up or down to change the opacity of a video clip or the volume of an
    audio clip (the same values as in the inspector, one undo step per change).

Version 1.3.1
-------------
  - Fixed: files chosen in the Import dialog (or dragged in) were not imported at all ("Cannot import ...: file not found"). The dialog hands the list over as a
    value wrapped inside another value and the import did not unwrap it. Found from the log of an affected PC; a test now uses exactly that shape.

Version 1.3.0
-------------
  - Tracks: the "+ Video" and "+ Audio" buttons under the track names add a track (up to 64); double-click a track name or use the right-click menu to rename it.
  - Right-click menu of a track: Rename, Lock, Add video / audio track, Remove track. A track that still has clips can be removed too: after a confirmation its
    clips are deleted with it (this cannot be undone, the undo history is cleared). The last video track and the last audio track always stay.

Version 1.2.0
-------------
  - Less duplication: the bar at the top now has only Home, Edit, Color and Export. Import, Audio, Effects and AI are tabs of the tool panel at the left only
    (they were buttons in both places). The Media, Audio, Effects and AI workspaces and their View-menu entries are gone.
  - A tab shows its content where the tab is: the AI tools now open in the left panel (they used to appear in the inspector at the right), and the audio
    mixer lives in the Audio tab only (it was also in the inspector).

Version 1.1.2
-------------
  - Import: files chosen in the file dialog are accepted however the list arrives (a list inside a list used to give "Cannot import : file not found" with an empty
    name), and a file that is only in the cloud (Google Drive / OneDrive "online only") is opened instead of being reported missing.
    The message now shows the full path, and the log (Help > Open log) records what the import received.
  - Fixed a harmless warning when closing a maximized window for the first time.

Version 1.1.1
-------------
  - Master level meter redesigned: dark track with green / amber / red LED segments, centred in its strip, with the dB scale set apart from the bars.
  - Button labels and icons are centred (they sat at the left edge of wide buttons, e.g. the workspace tabs and the V / B / N / Y / U tool buttons).
  - Timeline: a thin guide line with its time follows the mouse over the ruler and the tracks.

Version 1.1.0
-------------
  - New tool panel at the top left of the editor (like CapCut): tabs Import, Audio, Text, Effects, Transitions, Filters, Adjustment and AI.
    Text adds a title / lower third / caption; Effects, Transitions and Filters (colour looks) apply to the selected clip; Adjustment has the main colour sliders;
    Audio shows the mixer strips of the audio tracks; AI opens the AI workspace. Everything is undoable and uses the same functions as the inspector.
  - The master level meter (stereo, dB scale) is always visible at the right edge of the timeline; it was part of the audio mixer before.
  - The tool panel is wider by default and its tabs share the width (icons only when the panel is narrow).

Version 1.0.1
-------------
  - The installer no longer asks for a folder: the program always goes to ...\DriveVault\Common\DriveVault Video Editor Pro (the suite folder layout).
  - Internal: automated tests no longer play sound (environment variable DV_NO_AUDIO).
  - Can be installed over 1.0.0 with DriveVault Master Pro ("Check for updates") once this version is published as a GitHub Release.

Version 1.0.0  (first product release)
--------------------------------------
Status: release candidate quality. The installer is NOT code-signed yet (Windows SmartScreen will warn), and it has been
tested on development machines and with automated install / uninstall tests, not on a separate clean PC or a virtual machine.

DriveVault Master Pro (the suite hub, installed automatically)
  - Every program installer installs DriveVault Master Pro first, into C:\Program Files\DriveVault, with the programs in sub folders
    (C:\Program Files\DriveVault\Common\DriveVault Video Editor Pro). Master Pro lists the installed DriveVault programs, opens them, shows version / status
    in each program's own colour, installs and updates programs from setup files on this PC and uninstalls them. It stays when a program is
    uninstalled and cannot be uninstalled while any program is installed. There is no online catalog yet; Image Editor and Audio Editor are shown as "Coming soon".

New in the installer (Phase 6)
  - Installs by default to  C:\Program Files\DriveVault\Common\DriveVault Video Editor Pro  (all users, administrator rights asked once).
    A per-user install (no administrator) is offered by the wizard; the default is then %LOCALAPPDATA%\Programs\DriveVault\Common\DriveVault Video Editor Pro.
  - The program is self-contained: the Microsoft Visual C++ runtime is installed next to the program (earlier test installers
    relied on the runtime already being present on the PC - fixed).
  - Start Menu folder "DriveVault" (shared by future DriveVault programs), optional desktop shortcut, optional .dvproj association.
  - Product manifest (product.json) and registry entry for the future "DriveVault Master Pro" hub.
  - User guide (Thai / English), release notes and third-party notices in the Help menu.
  - Smaller download: unused FFmpeg libraries (avdevice, avfilter) and the Visual C++ redistributable installer are no longer included.

Feature summary (Phases 1-5)
  - Import, thumbnails, waveforms, relink; multitrack timeline with linked clips, snapping, undo / redo, auto-save and crash recovery.
  - Ripple / roll / slip / slide, copy / paste, groups, markers, In / Out, subtitle tracks.
  - Inspector: transform, colour, lift / gamma / gain, curves, .cube looks, blur / sharpen / vignette / crop, keyframes, transitions.
  - Titles, lower thirds, captions, SRT import / export. Per-clip audio (EQ, gate, fades), track mixer with meters.
  - Export MP4 / MOV / MKV (H.264 + AAC), audio-only M4A, presets, In-Out range, PNG frame; validation of every exported file.
  - AI (offline, optional): captions with whisper.cpp, silence detection and cutting, cut suggestions, noise reduction, tracking, assistant.
  - Performance: frame cache with read-ahead, proxy editing, hardware detection.
  - Thai / English user interface.

Installing without a digital signature
  The installers are not code-signed (a certificate has to be bought). Windows may therefore show a blue "Windows protected your PC" (SmartScreen) window or a
  yellow "Unknown publisher" prompt. Choose "More info" and then "Run anyway" (or "Yes" in the administrator prompt). This only means that the publisher is not yet known to Windows;
  the file's SHA-256 is published next to the installer (.sha256) so that you can check it.

Known limitations
  - Not code-signed. Not tested on a clean machine / VM.
  - Automatic captions are not always accurate. The speech model is not part of the installer (download or import it).
  - GPU video decoding is experimental and off by default (it was slower than the CPU on the test computer).
  - Noise reduction is signal processing, not a neural network.
  - Titles cannot be tracked or keyframed yet. No speed change / reverse, no nested sequences.
  - See the User Guide and README for the complete list.
