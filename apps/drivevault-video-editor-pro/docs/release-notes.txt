DriveVault Video Editor Pro - Release notes
==========================================

Version 1.11.1 (2026-11-09)
--------------
  - Fixed: the window did not open the way it was closed (maximized or normal, size and place) and the panel layouts were not remembered. The saved state was written
    as empty. It is stored correctly now, so from the next close on the program opens maximized or normal as you left it.

Version 1.11.0 (2026-11-08)
--------------
  - Mixer: the channel strips now start at the left edge. The High / Mid / Low EQ knobs belong to the audio TRACK (they used to change only the clip under the playhead):
    they filter everything on that track, play in the preview, are exported and are saved in the project (older project files open with the EQ flat). The per-clip
    EQ and volume stay in the Inspector. The "Gain" knob was removed from the strip - the fader of the strip is the track gain. The fader handle is centred on its slot.
  - Removed: AI "Edit by prompt" (the section in the AI tab, the language model and its Download card, the llama.cpp engine). It did not work well enough. The AI
    Assistant, captions, silence detection, cut suggestions, enhancement and tracking are unchanged.
  - The Whisper base speech model (about 142 MB, MIT) is now installed with the program, so auto captions work right after setup without a download.
    The installer is larger by about the size of the model.

Version 1.10.1 (2026-11-08)
--------------
  - Recent projects are no longer empty after a new install or an update on a PC that has no recent-projects list (for example after the settings were removed
    when uninstalling): the list is rebuilt from the projects in Documents\DriveVault Projects, newest first. A list you cleared yourself stays empty.

Version 1.10.0
--------------
  - The timeline stays smooth however much is on it. It used to build the on-screen parts of every clip at once (a project with 848 clips made about 20,000 of them), so
    opening, scrolling, zooming and playing became slow; now only the clips that are on screen (plus one screen on each side) exist, and clips that are only a few
    pixels wide are plain coloured blocks drawn together. Measured on a copy of a real project (848 clips) on the same build, old behaviour -> now: playback 14.7 -> 59 frames
    per second, the slowest frame while zooming 925 ms -> about 100 ms, the slowest frame while scrolling 169 ms -> about 80 ms; a 5,088 clip project (1 h 19 min)
    plays at 60 frames per second as well. A few single frames can still take 50-100 ms.
  - Timeline zoom: all the way out shows the whole project (it used to stop at about 1:40 of a 6:38 project), all the way in shows one frame 200 pixels wide (it was 40).
    Ctrl + mouse wheel zooms around the mouse (the frame under the mouse stays under the mouse); the buttons and keys zoom around the playhead. "Fit timeline" fits the whole project.
  - The pictures of a video clip are the real frames at their place in the clip (they used to be one picture repeated), so zooming in shows the frames; they are
    decoded in the background and the still thumbnail is shown until a frame is ready. Only the part of a clip that is on screen is painted (a clip can be millions of
    pixels wide when zoomed in).
  - The window remembers that it was maximized and opens maximized again (it did not when the window had been maximized from the first start). Master Pro 1.3.1 does the same.
  - The Mixer tab does no work while it is hidden.
  - Diagnostics: DriveVaultVideoEditorPro.exe project.dvproj --ui-bench report.txt scrolls, zooms and plays the open project and writes the frame timings;
    the environment variable DV_TIMELINE_ALL=1 switches back to building every clip (to compare).

Version 1.9.1
-------------
  - Fixed the Home screen: the three start buttons were wider than their column and ran into the recent projects panel; now "New Project" has its own wide button and
    "Open Project" and "Project from folder" share the row below it.
  - Fixed: a scroll bar track was always drawn, even when a list had nothing to scroll (visible on the recent projects list); scroll bars now appear only when needed.
  - The "Clear list" button and the remove buttons of the recent projects line up at the right edge.

Version 1.9.0
-------------
  - New: a local language model for "Edit by prompt". With it installed, the button "Understand with local AI" (Ctrl+Enter) turns a FREE sentence in Thai or English into the
    editing steps (for example "make it look like an old film", "open with a fade from black", "cut every 5 seconds and add a flash"). The steps are shown first and nothing
    changes until you press Edit; the whole prompt is still one undo step. Typing alone still shows the instant keyword plan.
  - The model is Qwen3.5 4B (Alibaba, Apache 2.0) run by llama.cpp (MIT) as a separate program on this PC only (127.0.0.1); nothing is sent anywhere. It is NOT installed
    with the program: press "Download" in the Speech models section (2.74 GB from Hugging Face; the size and SHA-256 are checked) or put the file in the model folder.
    It starts on the first request (about 3 GB of memory), stops after 10 idle minutes and can be switched off or deleted there.
  - Honest limits: it is a small model - in our own 30-sentence test (written by us, Thai and English) it understood 27 of 30 and answered in a median of 6 seconds on a
    Ryzen 5 7640HS without a graphics card; it can still pick a wrong name or add a step you did not ask for, which is why the plan is shown first. Without the model,
    or when it fails, the keyword plan is used as before.
  - Installer: the llama.cpp engine (about 45 MB) is installed in ai\llama with its licences; the installer test has 2 more checks (68).

Version 1.8.0
-------------
  - New: "Edit by prompt" (AI tab, first section). Type what you want in Thai or English - for example: place all clips, add the black and white filter, add the slide
    transition, add the text "Hello" at 3 seconds, export 1080p - and the steps it understood are listed. Press Edit and they are carried out as ONE undo step:
    place all clips, split at a time or every N seconds, add text, effects, transitions and filters (to every video clip, clip N or the selected clip), and start the
    export (an existing file is never overwritten silently). It works offline with a fixed set of words: it is NOT a language model, so free-form sentences are not
    understood; what it does not understand is listed and skipped. Put the words of a text in quotation marks.
  - New: "Project from folder" on the Home screen: choose a folder and a project named after it is created (size and frame rate of its first video) with every video,
    picture and audio file of the folder imported. The Import tab has a "Place all clips on the timeline" button (one undo step: videos and pictures one after another
    in name order, audio-only files on a music track from 0).
  - The AI tab is an accordion: one section is open at a time (remembered).
  - The mixer was re-arranged: the knobs are one line each (name, dial, value), the fader with its solo / mute buttons sits beside them, and the strips are centred.
  - Fixed: the dB scale of the faders was drawn on top of each other.

Version 1.7.0
-------------
  - Bigger catalogs, grouped like a mobile editor: Text 16 styles (Title, Lower third, Caption, Subtitle, Outline, Impact, Neon, Gold, Elegant, Handwriting,
    Typewriter ...), Effects 20 (blur and sharpen levels, vignettes, Dream, Focus, letterbox / cinema bars, zoom, tilt ...), Transitions 15 in / 7 out (wipe and slide
    in four directions, zoom in / out, spin, flash ...) and Filters 24 (Basic, Film, Mood). Every tile sets real clip parameters or a real transition; the
    renderer was extended, so preview and export show the same transitions. The text fonts Impact, Georgia, Segoe Script and Consolas are Windows fonts; Thai
    letters that these fonts lack are drawn with a fallback font.
  - The bottom panel has two tabs: Timeline and Mixer. The mixer has a channel strip for every audio track (fader, pan, solo, mute and the Gain / High / Mid / Low
    knobs of the clip under the playhead on that track) and a master fader at the right, next to the always-visible master meter. The master fader is a real
    project setting (saved in the project file, used by preview and export; projects from older versions open with 0 dB). The EQ and Gain knobs edit the clip under
    the playhead because the EQ belongs to clips, not to tracks.
  - Long values in the inspector (such as the project path) are cut with "..." and the full text is the tooltip.
  - The Audio tab of the tool panel now has Import audio, Add audio track and Open mixer (the strips moved to the mixer).

Version 1.6.0
-------------
  - The Effects, Transitions and Filters tabs show every tile on a drawn sample picture (a landscape, so no media file is needed) with the effect, the look or the
    transition applied; the preview plays when the mouse is over the tile and returns to the resting picture afterwards. Clicking a tile still applies the real
    effect / transition / look to the selected clip. The previews are an approximation drawn for the tile (the exported picture is made by the real renderer).
    Blur uses the graphics card; on a PC without one the blur tiles show the sample unblurred.

Version 1.5.0
-------------
  - Program monitor: click the picture to select the clip under the pointer (a click on an empty part clears the selection). A frame appears around the clip:
    drag inside it to move (snaps to the centre), drag a corner to scale, drag the round handle above it to rotate (snaps every 45 degrees). The values are the
    clip's Position, Scale and Rotation, so everything is undoable and is exported as shown. The frame is hidden while playing.

Version 1.4.0
-------------
  - Imported media are copied into a "medias" folder next to the project file (Settings > Editing > "Copy imported media into the project", on by default).
    The copy runs in the background, the original stays where it is, the same file is not copied twice, a file with the same name from another folder gets
    "(2)" and a file that cannot be read leaves no copy. Projects that already exist keep using their files where they are.
  - Tracks can be collapsed and expanded: the arrow in the track header, or right-click > Compact track / Normal height / Tall track. The height is saved
    with the project (older projects open with normal lanes).
  - Level line on every clip: move the mouse over a clip and a line appears; drag it up or down to change the opacity of a video clip or the volume of an
    audio clip (the same values as in the inspector, one undo step per change).

Version 1.0.0  (first product release)
--------------------------------------
Status: release candidate quality. The installer is NOT code-signed yet (Windows SmartScreen will warn), and it has been
tested on development machines and with automated install / uninstall tests, not on a separate clean PC or a virtual machine.

DriveVault Master Pro (the suite hub, installed automatically)
  - Every program installer installs DriveVault Master Pro first, into C:\Program Files\DriveVault, with the programs in sub folders
    (C:\Program Files\DriveVault\Common\DriveVault Video Editor Pro). Master Pro lists the installed DriveVault programs, opens them, shows version / status
    in each program's own colour, installs and updates programs from setup files on this PC and uninstalls them. It stays when a program is
    uninstalled and cannot be uninstalled while any program is installed. There is no online catalog yet; Image Editor and Audio Editor are shown as "Coming soon".

New in the installer (Phase 6)
  - Installs by default to  C:\Program Files\DriveVault\Common\DriveVault Video Editor Pro  (all users, administrator rights asked once).
    A per-user install (no administrator) is offered by the wizard; the default is then %LOCALAPPDATA%\Programs\DriveVault\Common\DriveVault Video Editor Pro.
  - The program is self-contained: the Microsoft Visual C++ runtime is installed next to the program (earlier test installers
    relied on the runtime already being present on the PC - fixed).
  - Start Menu folder "DriveVault" (shared by future DriveVault programs), optional desktop shortcut, optional .dvproj association.
  - Product manifest (product.json) and registry entry for the future "DriveVault Master Pro" hub.
  - User guide (Thai / English), release notes and third-party notices in the Help menu.
  - Smaller download: unused FFmpeg libraries (avdevice, avfilter) and the Visual C++ redistributable installer are no longer included.

Feature summary (Phases 1-5)
  - Import, thumbnails, waveforms, relink; multitrack timeline with linked clips, snapping, undo / redo, auto-save and crash recovery.
  - Ripple / roll / slip / slide, copy / paste, groups, markers, In / Out, subtitle tracks.
  - Inspector: transform, colour, lift / gamma / gain, curves, .cube looks, blur / sharpen / vignette / crop, keyframes, transitions.
  - Titles, lower thirds, captions, SRT import / export. Per-clip audio (EQ, gate, fades), track mixer with meters.
  - Export MP4 / MOV / MKV (H.264 + AAC), audio-only M4A, presets, In-Out range, PNG frame; validation of every exported file.
  - AI (offline, optional): captions with whisper.cpp, silence detection and cutting, cut suggestions, noise reduction, tracking, assistant.
  - Performance: frame cache with read-ahead, proxy editing, hardware detection.
  - Thai / English user interface.

Installing without a digital signature
  The installers are not code-signed (a certificate has to be bought). Windows may therefore show a blue "Windows protected your PC" (SmartScreen) window or a
  yellow "Unknown publisher" prompt. Choose "More info" and then "Run anyway" (or "Yes" in the administrator prompt). This only means that the publisher is not yet known to Windows;
  the file's SHA-256 is published next to the installer (.sha256) so that you can check it.

Known limitations
  - Not code-signed. Not tested on a clean machine / VM.
  - Automatic captions are not always accurate. The speech model is not part of the installer (download or import it).
  - GPU video decoding is experimental and off by default (it was slower than the CPU on the test computer).
  - Noise reduction is signal processing, not a neural network.
  - Titles cannot be tracked or keyframed yet. No speed change / reverse, no nested sequences.
  - See the User Guide and README for the complete list.
