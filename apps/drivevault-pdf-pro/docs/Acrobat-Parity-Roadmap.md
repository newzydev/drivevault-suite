# แผนทำ PDF Pro ให้ครบแบบ Acrobat Pro (เฉพาะที่ทำในเครื่องได้) และ UI ของเราเอง

เจ้าของเลือกเมื่อ 2026-11-12: ขอบเขต = **ทุกอย่างที่ทำในเครื่องได้**, UI = **shell ใหม่ของเราเอง** (ไม่ลอกของ Adobe)
ไม่ทำ: AI Assistant, Adobe Sign / ลงนามออนไลน์, แชร์และคลาวด์, แปลง Office/HTML (ถ้าต้องการ ต้องขออนุญาตโหลด LibreOffice ก่อน)
รายการเทียบ 114 ข้อและสถานะอยู่ใน `Full-Feature-Phase-0-Audit.md`

| เฟส | งาน | สถานะ |
|---|---|---|
| A | Shell ใหม่: ชุดไอคอนทั้งโปรแกรม, แถบเครื่องมือแบบไอคอน, แถบซ้ายแบบ rail (ภาพย่อ / บุ๊กมาร์ก / คอมเมนต์ / ไฟล์แนบ), แผงเครื่องมือขวาตามบริบท, ธีมพรีเมียม | ทำแล้วบางส่วน: ตัวควบคุมชุดเดียว (v1.9.3), แถบเครื่องมือไอคอน (v1.9.4), แผงเครื่องมืออยู่ขวา (v1.10.0) ยังไม่ทำ: แถบ rail ซ้ายแบบไอคอนอย่างเดียว, ธีมพรีเมียมเพิ่ม |
| B | อ่านและนำทางครบ: ปรับซูมเอง, fit height, มือจับเลื่อน, โหมดหน้าเดียว/ปก, ชั้น (layers), page labels, อ่านออกเสียง (TTS), ตรวจสอบสแนปช็อต | ยังไม่เริ่ม |
| C | แก้ไขเนื้อหา: แก้ย่อหน้า/แทรก/ย้ายข้อความเดิมให้กว้างขึ้น, แทนที่/ครอปรูปเดิม, เส้นไกด์และ snap, Bates / header-footer / พื้นหลังเต็ม | ทำแล้วบางส่วน: เลข Bates ในหัว/ท้ายกระดาษ (v1.10.0) |
| D | ฟอร์ม: สร้างฟอร์มเอง (ช่องข้อความ ติ๊ก รายการ ปุ่ม ลายเซ็น), กรอกบนหน้าโดยตรง, ส่งออก/นำเข้าข้อมูลฟอร์ม | ทำแล้วบางส่วน (v1.11.0): สร้างช่องข้อความ ช่องติ๊ก รายการเลือกเอง ยังไม่ทำ: กรอกบนหน้าโดยตรง, ปุ่ม/ช่องลายเซ็น/radio, ส่งออก/นำเข้าข้อมูลฟอร์ม |
| E | รีวิวและคอมเมนต์: กล่องโน้ต, ตราประทับ, markup แบบ annotation แก้ภายหลังได้, รายการคอมเมนต์, เปรียบเทียบสองไฟล์ | ทำแล้วบางส่วน: เปรียบเทียบสองไฟล์ (v1.10.0) |
| F | ลายเซ็นดิจิทัลในเครื่อง (ใบรับรองของผู้ใช้), ตรวจลายเซ็น, ตรวจ accessibility / preflight, PDF/A ที่ผ่าน validator อิสระ | ทำแล้วบางส่วน (v1.11.0): ลงนามสำเนาด้วยใบรับรอง .pfx และตรวจลายเซ็น ยังไม่ทำ: ลายเซ็นที่มองเห็น, ลงนามซ้ำ/ไฟล์มีรหัสผ่าน, accessibility/preflight, PDF/A |
| G | ชุดงาน (batch) เพิ่ม, portfolio, สคริปต์/actions ที่ผู้ใช้บันทึกเอง | ยังไม่เริ่ม |

กติกา: ทำทีละเฟสจนเสร็จและทดสอบ แล้วถามเจ้าของก่อนไปเฟสต่อไป ไม่ติดป้ายว่าทำแล้วถ้ายังไม่ผ่านเทสต์
