DriveVault PDF Pro 1.9.1

ติดตั้งและเปิด PDF อ่าน ค้นหา และพิมพ์ จัดหน้า บีบอัด และแก้ไข ส่งออก ป้องกัน และปิดบัง เมทาดาทา งานชุด และซ่อมไฟล์

ติดตั้งและเปิด PDF

เทียบค่า SHA-256 ของตัวติดตั้งกับไฟล์ที่ให้มา แล้วเลือกขอบเขตการติดตั้ง ตัวติดตั้งรวม Master Pro และจะติดตั้งหรืออัปเดตเมื่อจำเป็น เปิด PDF Pro จากเมนูเริ่ม Master Pro หรือ Open with ใน Windows คุณเลือกโปรแกรมอ่าน PDF เริ่มต้นได้จาก Windows

อ่าน ค้นหา และพิมพ์

ใช้คำสั่งเปิดหรือบันทึกเวิร์กสเปซแท็บจากเครื่องมือทั้งหมดหรือ Ctrl+K ไฟล์เวิร์กสเปซเก็บพาธ PDF ในเครื่องตามลำดับแท็บเป็นข้อความธรรมดา เปิดไฟล์เดิมกลับได้เมื่อพาธเหล่านั้นยังใช้งานได้

เลือกหรือลาก PDF หลายไฟล์เพื่อเปิดตามลำดับ ยกเลิกกล่องรหัสผ่านเพื่อข้ามไฟล์นั้น กด Ctrl+Shift+T เพื่อเปิดแท็บที่เพิ่งปิด หากไฟล์ต้นทางของฉบับร่างอาจเปลี่ยนไป ให้อ่านคำเตือนก่อนกู้คืน

ไฟล์ที่เปิดครั้งแรกแสดงที่ซูม 100% พร้อมแผงเครื่องมือทั้งหมด เลือกพอดีความกว้างหรือพอดีหน้าเพื่อย่อหรือขยายตามพื้นที่ เปิดภาพย่อจากแถบตัวอ่านได้เมื่อต้องการ

แถบเครื่องมืออ่านเอกสารอยู่เหนือแผงด้านซ้าย คลิกข้อความที่เลือกได้เพื่อวางเคอร์เซอร์กะพริบ ลากเมาส์หรือกด Shift ค้างแล้วคลิกเพื่อเลือกช่วงข้อความ จากนั้นกด Ctrl+C เพื่อคัดลอก

เลือก ไทย หรือ EN จากแถบชื่อ เปิดเมนู ⋯ เพื่อสลับธีม เปิดการตั้งค่า หรือดูเวอร์ชันและเลขบิลด์ในหน้าต่างเกี่ยวกับ การตั้งค่ายังใช้ปรับสีหน้า PDF ได้ด้วย

ลากแถบชื่อเพื่อย้ายหน้าต่าง ดับเบิลคลิกที่แถบเพื่อขยายหรือคืนขนาด และลากขอบหน้าต่างเพื่อปรับขนาด PDF Pro จำขนาด ตำแหน่ง และสถานะขยายหน้าต่าง วางเมาส์บนชื่อเครื่องมือที่ถูกตัดเพื่ออ่านข้อความเต็ม

เปิดหลายไฟล์เป็นแท็บ ใช้แถบด้านข้างดูภาพย่อ บุ๊กมาร์ก และความเห็น ปรับให้พอดีหน้า ซูม หรือหมุนมุมมอง กด Ctrl+F เพื่อค้นหา Ctrl+C เพื่อคัดลอก และ Ctrl+P เพื่อพิมพ์

กลับหน้าหลักได้โดยเก็บแท็บที่เปิดไว้ เลือกจากแถบเครื่องมือทั้งหมดหรือกด Ctrl+K เพื่อค้นหาคำสั่ง ใช้ OCR เอกสารสแกนภาษาไทยกับ PDF ที่ปลดล็อกแล้ว เลือกหน้าและบันทึกสำเนาที่ค้นหาได้ ผลจะแสดงจำนวนหน้าที่เพิ่มข้อความ หน้าที่ข้ามเพราะมีข้อความอยู่แล้ว และหน้าที่ OCR ไม่พบข้อความ โปรดตรวจข้อความที่อ่านได้ก่อนนำไปใช้

ในหน้าหลัก ค้นหาไฟล์ล่าสุดจากชื่อหรือเส้นทาง คลิกชื่อเพื่อเปิดไฟล์อีกครั้ง ใช้ไอคอนโฟลเดอร์เพื่อเปิดตำแหน่งไฟล์ หรือใช้ไอคอนปิดเพื่อเอารายการออก

จัดหน้า บีบอัด และแก้ไข

หากต้องการลบชุดข้อความเดิมที่รองรับ ให้เลือกแก้ข้อความเดิม คลิกชุดข้อความ แล้วเลือก “ลบชุดข้อความที่เลือกออกจากสำเนา” จากนั้นบันทึกเป็น PDF ใหม่ สำหรับข้อมูลลับให้ใช้เครื่องมือปิดบังข้อมูล PDF

ในหมวดแปลงไฟล์ เลือกสร้าง PDF เปล่าหรือสร้าง PDF จากรูปภาพ แล้วกำหนดขนาดกระดาษ แนวกระดาษ และระยะขอบ สำหรับรูปภาพให้เพิ่มไฟล์ PNG, JPEG หรือ BMP แล้วใช้ปุ่มเลื่อนและหมุนจัดลำดับก่อนบันทึก PDF ใหม่ แต่ละรูปจะแสดงพอดีในหนึ่งหน้า

ใช้จัดหน้าเพื่อเรียง ตัดขอบ หมุน และแทรกหน้า ใช้รวมไฟล์ที่หน้าแรกหรือแยกไฟล์ในหน้าอ่าน โปรดอ่านคำเตือนเกี่ยวกับบุ๊กมาร์กและฟอร์ม บีบอัดแสดงขนาดและภาพตัวอย่าง แก้ไขใช้เพิ่มข้อความ ภาพ และเครื่องหมาย ฟอร์มใช้กรอก AcroForm ที่รองรับ บันทึกการแก้ไขเป็นสำเนาใหม่

เลือกแก้ข้อความเดิมแล้วคลิกข้อความแนวนอนที่รองรับ พิมพ์ข้อความให้พอดีกับความกว้างเดิมแล้วบันทึกเป็นสำเนาใหม่ ข้อความใหม่ใช้ Noto Sans Thai โหมดนี้ไม่รองรับไฟล์เข้ารหัส ไฟล์ที่มีลายเซ็นดิจิทัล หรือข้อความที่ถูกแปลงเป็นเส้นเวกเตอร์

ส่งออก ป้องกัน และปิดบัง

ใช้เมนูส่งออกเพื่อส่งเป็น PNG หรือ JPEG เก็บหลายหน้าเป็น ZIP หรือโฟลเดอร์ ป้องกันสำเนาด้วย AES-256 หรือปลดล็อกเมื่อมีสิทธิ์และรหัสที่ถูกต้อง ในปิดบังข้อมูล PDF ให้ลากกรอบหรือค้นหาแล้วทำเครื่องหมาย โหมดเฉพาะจุดเก็บข้อความและเวกเตอร์ที่รองรับ โหมดสำเนาแบบภาพจะเอาชั้นข้อความค้นหาและโครงสร้างโต้ตอบออกทั้งสำเนา โปรดตรวจผลก่อนส่งต่อ

เมทาดาทา งานชุด และซ่อมไฟล์

หากต้องการรายงานสำหรับช่วยตรวจปัญหา ให้เรียก DriveVaultPdfPro.exe --diagnostics-json "C:\path\report.json" ด้วยชื่อไฟล์ใหม่ รายงานในเครื่องมีเวอร์ชัน เลขบิลด์ ข้อมูล Qt และระบบปฏิบัติการ สถาปัตยกรรม และสถานะการพบไฟล์รันไทม์กับโมเดล OCR

เมทาดาทาและไฟล์แนบแสดงเวอร์ชัน PDF จำนวนหน้า สถานะการเข้ารหัส และชื่อทรัพยากรฟอนต์ที่พบ การล้างข้อมูลยังลบ action ภายนอกที่รองรับ เช่น คำสั่งเปิดไฟล์หรือส่งฟอร์ม สำหรับข้อมูลลับในเนื้อหาหน้าให้ใช้เครื่องมือปิดบังข้อมูล PDF

ใช้เมทาดาทาและไฟล์แนบเพื่อแก้ข้อมูลและลบไฟล์แนบ เนื้อหาหน้าหรือเลเยอร์ที่ซ่อนอาจยังมีข้อมูลส่วนตัวหลังล้างข้อมูล ทำ PDF เป็นชุดทำงานทั้งโฟลเดอร์และรายงานผลรายไฟล์ ซ่อม PDF สร้างโครงสร้างที่ยังพอกู้ได้ การเขียนใหม่อาจทำให้ลายเซ็นเดิมใช้ตรวจสอบไม่ได้ ดูประกาศในโฟลเดอร์ licenses การถอนการติดตั้งเก็บเอกสารและข้อมูลโปรแกรมไว้
