DriveVault PDF Pro - release notes
==================================
(Release notes for DriveVault PDF Pro. Installer publication is recorded separately.)

v1.3.1 (2026-11-12): Refine text selection and the reader toolbar
  - Click selectable text to place a blinking caret. Drag or Shift-click to extend the selection from a character boundary.
  - Reader controls are grouped in a full-width toolbar above the side panels and document.
  - The installer is unsigned. Clean Windows installation remains an owner-run check.

v1.3.0 (2026-11-12): Refresh Home and improve recent file navigation
  - Search the full recent file history by name or path and open the containing folder from each row.
  - Home adapts its tool grid and document list to the available width in both themes.
  - The installer is unsigned. Clean Windows installation remains an owner-run check.

v1.2.0 (2026-11-11): Add appearance controls and app information
  - Switch language and the dark or light app theme using one button each in the title bar.
  - Settings controls display language, the app theme and PDF page colors. About shows the version and build number.
  - The installer is unsigned. Clean Windows installation remains an owner-run check.

v1.1.3 (2026-11-11): Refresh the Home tools
  - Give opening a PDF its own panel and arrange recommended tools in a responsive grid.
  - Bring Merge files into the grid and keep batch and repair actions beside the section heading.
  - The installer is unsigned. Clean Windows installation remains an owner-run check.

v1.1.2 (2026-11-11): Match the DriveVault title bar
  - Use a dark title bar with the PDF Pro icon, language switch and window controls.
  - Drag the title bar to move, double-click to maximize or restore, and drag the frame edges to resize.
  - The installer is unsigned. Clean Windows installation remains an owner-run check.

v1.1.1 (2026-11-11): Fit tool labels and remember the window
  - Long labels and descriptions on Home tool cards end with an ellipsis, with the full text on hover.
  - Reopening restores the normal window size and position or the maximized state.
  - The installer is unsigned. Clean Windows installation remains an owner-run check.

v1.1.0 (2026-11-11): Add PDF workspace, Thai OCR and text replacement
  - Home, document tabs, All tools and Ctrl+K command search.
  - Recognize Thai and English on image-only pages locally and save a searchable copy.
  - Replace supported horizontal text runs with shaped, searchable Thai or English.
  - The installer is unsigned. Clean Windows installation remains an owner-run check.

v1.0.0 (2026-11-09): First Windows installer candidate
  - English and Thai setup and user guides, optional desktop shortcut and Windows Open with registration.
  - Includes DriveVault Master Pro 1.5.5 and registers PDF Pro in the suite.
  - Installer is unsigned in local verification. Clean Windows installation remains an owner-run check.

v0.10.0 (2026-11-09): Add PDF maintenance, batch processing and repair
  - Edit title, author and keywords, inspect or remove named attachments, and clean private document data in a new copy.
  - Batch compress, watermark or protect files in a folder, with a report for each file.
  - Rebuild recoverable PDF structures into a new copy and verify that the result opens.

v0.9.0 (2026-11-09): Keep searchable text and vectors in verified redaction
  - Selective mode rebuilds supported content from scratch. It omits marked characters, cuts intersecting rectangles, and replaces marked pixels in supported images.
  - It verifies searchable text, hidden text and rendered pixels before saving. Unsupported PDFs can be processed by explicitly choosing Image-only copy.

v0.8.0 (2026-11-09): Add verified redaction to an image-only PDF
  - Draw areas or mark text with literal search, regular expressions and presets. Review each mark and choose a color or optional label.
  - Replace marked pixels and build a new PDF from sanitized page images. The copy drops searchable text and interactive structures on every page.
  - Verify the PDF structure, image data, extracted text and mask appearance before publishing the copy.

v0.7.0 (2026-11-09): Phase 5 adds image export and PDF protection
  - Export selected pages as PNG (optional transparency) or JPEG (adjustable quality), at 72–600 DPI.
  - Save one image, a ZIP, or a new image folder. Multi-page export shows progress and can be cancelled.
  - Protect a new copy with AES-256, separate open and owner passwords, and permission settings.
  - Unlock to a new copy with a correct password. PDFs that open without a password require the owner password.

v0.6.0 (2026-11-09) - Phase 4 finished: forms, notes, polygons, autosave
  New
  - Fill in forms (button "Form"): AcroForm text fields, tick boxes, lists and radio groups; saved as a new copy that every viewer shows.
  - The reader now draws form fields and their values (before, fields were blank).
  - Sticky notes and polygons in the edit bar.
  - Autosave of unsaved edits and an offer to restore them when the file is opened again.
  Limits
  - Forms: no XFA, no Thai in fields (the form fonts have none), no signatures; tested on a generated form only.
  - Edits are still burned into the pages when saved (no editable annotations).

v0.5.0 (2026-11-09) - Phase 4: add text, pictures and shapes
  New
  - Edit bar: text (Thai and English, shaped), pictures, rectangle, ellipse, line, arrow, pen, highlight, underline, strike-out, stamps; select, move, resize, turn, order, colour, fill, line width, opacity, font, size, bold, italic, alignment; undo / redo.
  - Watermark, page numbers, header and footer on every page (or a range).
  - Saved as a new file with the things burned into the pages; added text can still be searched and copied. A protected file stays protected.
  - Asks before closing a file or the program with unsaved edits.
  Limits
  - Not done: form filling, sticky notes, polygons, editable annotations, autosave. The saved things cannot be edited again as objects.

v0.4.0 (2026-11-09) - Phase 3: compress
  New
  - Compress (button "Compress"): Safe / Balanced / Smallest / custom; picture resolution (dpi) and JPEG quality, remove metadata and thumbnails, fast web view. Shows sizes and picture counts and one page before / after; the file is saved only when you choose "Save as" (never over the original). A file that would not get smaller is not written.
  - A protected file stays protected (same password).
  Limits
  - Only embedded pictures are touched (see README: black/white scans, JPEG 2000, CMYK, masked pictures are left alone); fonts are not touched.
  - Measured on generated files only.

v0.3.0 (2026-11-09) - Phase 2: merge, split and organize pages
  New
  - Organize pages: thumbnails, select (Ctrl / Shift), drag to reorder, delete, duplicate, turn, crop margins, blank pages, pages of other files, undo / redo. Saves a new file; the original is never changed and an existing file is replaced only after a question.
  - Merge files (Home screen, or add files inside the organizer). Protected files ask for their password.
  - Split: page ranges, every N pages, top level bookmarks, or a maximum file size; shows the files before writing; a failed or cancelled split removes what it wrote.
  - qpdf 12.4.2 (Apache-2.0) is used for the file structure.
  Limits
  - Bookmarks and form fields are not copied; links to pages that are not in the new file are removed; the result of a protected file is unprotected.
  - Crop hides the margins; the content stays in the file.
  Changed
  - The tool bar wraps to a second line on narrow windows (it ran out of the window at 1240 px).

v0.2.0 (2026-11-09) - Phase 1: the reader is complete
  New
  - Several files at once in tabs; the same file is not opened twice.
  - Find in the whole file: match case, whole word, highlights, next / previous (Ctrl+F, F3, Shift+F3).
  - Select text with the mouse (also across pages), copy with Ctrl+C or the right click menu, select all.
  - Bookmarks (outline) panel, comments / markup list, links inside the file (to a page, or to a web address after a question; only http, https and mailto).
  - Two pages per row, rotate the view, dark pages (view only), full screen (F11).
  - Printing: printer, page range, copies, colour, fit to paper.
  - The page, zoom and view mode of each file are remembered.
  Changed
  - A page image is limited to 64 million pixels (was 150 million) to keep the memory use of an extreme zoom down.
  Not done yet
  - See README.md: merge / split, compress, edit, export, protect, redaction, installer.

v0.1.0 (2026-11-09) - first version
  - Open a PDF, continuous pages, thumbnails, page field, zoom and fit, files with a password, recent files, drag and drop, Thai / English.
