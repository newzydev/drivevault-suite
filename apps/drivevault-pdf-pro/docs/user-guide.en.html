Install and open a PDF

Verify the setup SHA-256 against the accompanying file. Choose an installation scope. Setup includes Master Pro and installs or updates it when needed. Start PDF Pro from the Start menu, Master Pro or Windows Open with. Windows lets you choose your default PDF reader.

Read, search and print

Open several files in tabs. Use the sidebar for thumbnails, bookmarks and comments. Fit the page or width, zoom, or rotate the view. Ctrl+F searches, Ctrl+C copies selected text, and Ctrl+P opens printing.

Organize, compress and edit

Use Pages to reorder, crop, rotate and insert pages. Merge from Home or Split in the reader. Review warnings about bookmarks and forms. Compress previews size and appearance. Edit adds text, images and marks. Form fills supported AcroForm fields. Save your edits as a new copy.

Export, protect and redact

Use Output to export PNG or JPEG, save multiple pages as a ZIP or folder, protect a copy with AES-256, or unlock with a correct password and permission. In Redact PDF, draw boxes or search and mark matches. Selective mode preserves supported text and vectors. Image-only mode removes searchable text and interactive structures across the copy. Review the saved result before sharing.

Metadata, batch and repair

Edit metadata and remove attachments in Metadata and attachments. Cleanup can leave private information in page content or hidden layers. Batch PDF processes a folder and reports each result. Repair PDF rebuilds recoverable structures. Rewriting may invalidate signatures. Notices are in the installed licenses folder. Uninstall keeps your documents and app data.
