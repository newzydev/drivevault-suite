Install and open a PDF

Verify the setup SHA-256 against the accompanying file. Choose an installation scope. Setup includes Master Pro and installs or updates it when needed. Start PDF Pro from the Start menu, Master Pro or Windows Open with. Windows lets you choose your default PDF reader.

Read, search and print

Select or drop several PDFs to open them in order. Cancel a password prompt to skip that file. Ctrl+Shift+T reopens the most recently closed tab. If the source of an unsaved draft may have changed, review the warning before restoring it.

New files open at 100% zoom with All tools visible. Choose Fit width or Fit page to scale the page to the available space. Open thumbnails from the reader toolbar when needed.

The reader toolbar spans the window above the side panels. Click selectable text to place a blinking caret, then drag or Shift-click to select a range. Ctrl+C copies the selection.

Choose ไทย or EN in the title bar. Open the ⋯ menu to switch the app theme, open Settings, or see the version and build number in About. Settings also controls PDF page colors.

Drag the title bar to move the window, double-click it to maximize or restore, and drag an edge to resize. PDF Pro remembers the window's normal size and position and whether it was maximized. Hover over a shortened tool label to read the full text.

Open several files in tabs. Use the sidebar for thumbnails, bookmarks and comments. Fit the page or width, zoom, or rotate the view. Ctrl+F searches, Ctrl+C copies selected text, and Ctrl+P opens printing.

Home keeps your open documents in tabs. Browse All tools or press Ctrl+K to find a command. Use Scan & OCR (Thai) on an unlocked scan, choose the pages, and save a searchable copy. Pages that already contain text are skipped. Review recognized text before relying on it.

On Home, search Recent files by name or path. Select a file to reopen it, use the folder icon to open its location, or remove the entry from the list with the close icon.

Organize, compress and edit

Use Pages to reorder, crop, rotate and insert pages. Merge from Home or Split in the reader. Review warnings about bookmarks and forms. Compress previews size and appearance. Edit adds text, images and marks. Form fills supported AcroForm fields. Save your edits as a new copy.

Use Edit existing text and click a supported horizontal text run. Enter a replacement that fits the original width and save a new copy. The text uses Noto Sans Thai. Encrypted and signed PDFs, vector outlines and unsupported text runs cannot be edited this way.

Export, protect and redact

Use Output to export PNG or JPEG, save multiple pages as a ZIP or folder, protect a copy with AES-256, or unlock with a correct password and permission. In Redact PDF, draw boxes or search and mark matches. Selective mode preserves supported text and vectors. Image-only mode removes searchable text and interactive structures across the copy. Review the saved result before sharing.

Metadata, batch and repair

Edit metadata and remove attachments in Metadata and attachments. Cleanup can leave private information in page content or hidden layers. Batch PDF processes a folder and reports each result. Repair PDF rebuilds recoverable structures. Rewriting may invalidate signatures. Notices are in the installed licenses folder. Uninstall keeps your documents and app data.
