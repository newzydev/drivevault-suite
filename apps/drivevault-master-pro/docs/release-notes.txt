DriveVault Master Pro - release notes
=====================================

v1.3.0
  New
  - New look: a hero at the top (headline and a search field that filters the programs by name and description, and an updates badge when there is one),
    programs grouped in sections, cards that lift under the mouse.
  - Calmer screen: the top bar has only the language switch, "Check for updates" and a "..." menu (add installer folder, open installers folder, check for
    updates on start, about); the Refresh button and the installer-folder list at the bottom are gone (the list refreshes itself); a program card has "Open"
    and a "..." button (open folder, uninstall) instead of two extra buttons; the hero shows an updates badge only when there is an update.
  - Sections: "Multimedia programs" (Video Editor Pro, Image Editor Pro, Audio Editor Pro) and "Office programs" (Document Pro, Presentation Pro, Spreadsheet Pro,
    PDF Pro). The office programs do not exist yet: they are shown as "Coming soon" and cannot be installed. Programs the hub does not know go to "Other programs".

v1.2.0
  New
  - Checks for updates automatically once when it opens (all programs and Master Pro itself). The checkbox "Check for updates on start" in the footer switches it off.
    The check is quiet: nothing is shown when it fails or when everything is up to date. Nothing is downloaded until you press an update button.
  - Master Pro can update itself: a banner "Master Pro x.y.z is available" with an "Update Master Pro" button (download, SHA-256 check, setup closes and restarts Master Pro).
  - The window remembers whether it was maximized and its normal size and place.
  - New look for the buttons (gradient accent button, softer secondary and delete buttons); the actions of a program card no longer overflow the card.

v1.1.1
  - Fixed: the Thai texts of "Check for updates" and the download were garbled.
  - An empty release list now says that no releases have been published yet (it used to say "up to date").
  - Release tags are the program folder name + version, e.g. drivevault-video-editor-pro-v1.0.1 (v1.1.0 looked for shorter names and found nothing).

v1.1.0 (2026-11-07)
  New
  - "Check for updates" button: asks the GitHub Releases of newzydev/drivevault-suite which version of each program exists. It runs only when you press the button;
    nothing is checked or downloaded in the background.
  - "Download version X and update / install": downloads the setup file from the official release address, compares its SHA-256 with the release's .sha256 file,
    checks that it is the right DriveVault program and version, then runs it like any other setup file. The downloaded file is deleted after a successful run.
  Changed
  - The licence text (EULA) says that "Check for updates" contacts GitHub.
  - Fixed: the Thai product section (6) of the licence text was shown garbled; the licence generator script is now saved with a byte order mark.
  Notes
  - (1.1.0 only) Master Pro did not update itself; since 1.2.0 it does.
  - GitHub limits anonymous requests (60 per hour per connection): if the check says so, try again later.

Known limitations
  - Installers are not code-signed (a certificate has to be bought). Windows may show "Windows protected your PC": choose "More info" and then "Run anyway".
    The SHA-256 check above protects against a damaged or swapped download, not against a compromised release.
  - Not tested on a clean machine / VM.

v1.0.0
  - First release: lists, opens, installs, updates (from setup files on this PC) and uninstalls DriveVault programs; installed automatically by every program installer.
