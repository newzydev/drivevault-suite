DriveVault Master Pro - release notes
=====================================

v1.16.0 (2026-11-17): Conversations in folders, and a right panel with git, context and changes
  - Left side of the agent page: the conversations are grouped by the folder they work in (a group per folder, the newest first). A group can be closed with a click on its header, and its "+" starts a new conversation in that folder. Opening a conversation puts the work back in its folder; choosing another folder starts a new conversation.
  - Right side: "Environment" (this computer, the folder - click to change it, the git branch with how far it is ahead / behind), "Context" (how much of the model window this conversation uses, in % and tokens: the number the model server counted, or an estimate marked "about"), "Changes" (the files git says changed, with M / A / D / ? marks and +lines / -lines, refreshed after every change, every answer and with the refresh button) and "Connectors" (the web switch, git and commands - the real tools of this page; there are no other connectors).
  - Changes are read with `git status` and `git diff --numstat` (read only, never anything that changes a repository). It needs git on this PC; the panel says so when it is missing or the folder is not a repository.
  - Not code-signed (Windows SmartScreen may warn).

v1.15.0 (2026-11-17): The agent page shows what the AI is doing, step by step
  - New: a box "What the AI does" lists every step as a line - read / list / search / find files, create or edit a file (with its name), run a command, search the web, open a page - with a turning ring while the step runs, a green tick when it is done, a red cross and the reason when it failed, and "waiting for you" while it waits for your Allow. It stays open on the newest answer and can be opened or closed with a click on its header. The lines are saved with the conversation.
  - New: the plan of the AI (its task list) is a checklist box in the conversation, with a tick in front of what is done, the item being worked on marked, and a progress bar. The plan is saved with each conversation (it was only in the side panel and lost when you changed conversation); the plan list of the side panel is gone because the box replaces it.
  - The page shows what the program knows: the calls and their results and the notes of the agent (made room, asked again). The reasoning of the model itself is still never shown.
  - Not code-signed (Windows SmartScreen may warn).

v1.14.1 (2026-11-16): Updates close the program, show the installer and open the program again
  - When Master Pro updates itself or another program, the installer now appears at once: it closes the running program by itself (no question), skips the questions (welcome, licence, options, ready page), installs, and when you press Finish the program starts again as before. If the update of Video Editor Pro or PDF Pro also had to update Master Pro (which closes it), Master Pro opens again after Finish too.
  - The same behaviour applies when you double-click a newer setup file over an installed version. A first install is unchanged.
  - Built, not run: the real installer wizard was not tried (the installer test is yours).
  - Not code-signed (Windows SmartScreen may warn).

v1.14.0 (2026-11-16): The agent works until the job is done; clock and animations
  - Agent: no limit on the number of steps any more (a safety net of 60 / 400 / 1000 remains). A job ends when the model is done, when you press Stop, or when it is stuck (the same call 8 times in a row). The model window is now 32768 tokens (was 8192) and the answer limit 8192 (was 3000), so a whole page fits in one answer; the conversation is kept inside the window (old results are shortened, then dropped; the task stays); a long answer goes on where it was cut; a long file is read in parts (start_line); a silent answer is asked again; an answer while the task list still has open items is not accepted. Every such step shows a line in the activity list. The model may use more memory because of the larger window.
  - The instructions to the model are rewritten: small request = just do it; big job = look, task list, do the items, check the result, summary; read errors and take another way.
  - Page: a clock that runs while the AI works (title bar of the page, status line and the answer) and "Took m:ss - n steps" under every answer; a light runs above the message box and its edge breathes while the AI works; new messages fade in; the task list shows 3 / 7 with a growing bar and animated items; the approval card pops in; three dots show the AI is working.
  - Not code-signed (Windows SmartScreen may warn).

v1.13.1 (2026-11-16): A long file no longer ends in "error 500"
  - Fixed: when the model wrote a long file in one go, its answer was cut off by the length limit and the page showed "the local model answered with error 500" with the whole file in the message. Now the agent tells the model that the answer was cut off and asks again for a shorter one (twice at most), the instructions tell the model to write big files in parts (write_file, then edit_file), and a long error message is cut to 600 characters.
  - Not code-signed (Windows SmartScreen may warn).

v1.13.0 (2026-11-16): The agent works like Claude Code
  - New tools: edit_file (one exact piece of text replaced; the approval card shows a red / green diff), glob_files (find files by name), a task list (todo_write; shown in the right panel).
  - New: plan mode is real. The AI explores, then shows its plan; nothing is changed or run until you press "Approve and start" (then the page goes to "Ask first"), or you ask it to keep planning.
  - New: the AI can run a command (cmd.exe, in the working folder) in the "Ask first" and "Accept edits" modes. EVERY command is shown to you first and runs only after you press Allow. It runs with your permissions and is not limited to the folder; it has no input, a 60 second limit (300 at most) and Stop kills it. This replaces the earlier rule that the agent could not run programs.
  - New: slash commands /help /clear /new /mode /effort /web /todos /init; Esc stops the work; Shift+Tab changes the mode; the CLAUDE.md (or AGENTS.md) of the working folder is given to the model.
  - Not code-signed (Windows SmartScreen may warn).

v1.12.3 (2026-11-16): The agent no longer searches the web for ever
  - Fixed: a small model could call web_search again and again (12 times in a row) and then stop with "used the tools too many times". Now the same web call is not run twice and a task may make at most 4 web calls (search + open page); after that the model is told to do the task with what it has.
  - Not code-signed (Windows SmartScreen may warn).

v1.12.2 (2026-11-16): Agent folder fix
  - Fixed: after choosing a folder on the Agentic AI page the Send button stayed disabled and the page still asked for a folder (the folder address from the dialog was kept as "file:/C:/..." instead of a path). A folder saved this way by 1.12.0 / 1.12.1 is repaired when the program starts.
  - Not code-signed (Windows SmartScreen may warn).

v1.12.1 (2026-11-15): Gear icon
  - The menu button in the title bar now shows a gear instead of three dots (the same gear in all DriveVault programs). It opens the same menu.
  - Not code-signed (Windows SmartScreen may warn).

v1.12.0 (2026-11-15): Modes of the agent
  - New: the agent page has a Mode menu under the message box: Read only (look and answer), Plan (look, then write a plan of the steps; nothing is changed), Ask first (the default: every file change is shown to you - path, size, a preview of the content - and is made only if you press Allow; "Don't allow" tells the AI so) and Accept edits (changes are made without asking; a file that is replaced is first saved in .drivevault-backup).
  - The page shows "Waiting for your answer" while a change waits; Stop ends it. No mode lets the AI run programs or delete files.
  - An older choice "can edit files" becomes Accept edits; the old default (read only) becomes Ask first.
  - Not code-signed (Windows SmartScreen may warn).
v1.11.0 (2026-11-15): Only the model on this PC; model and effort in the chat
  - Changed: the AI pages now use ONLY the model on this PC. The API (OpenAI style, Anthropic), Claude Code and Codex are gone, together with the API keys: nothing of them is left in the program or its settings. A conversation you already had is kept.
  - New: the message box has a model menu (the models installed on this PC, and "Manage models...") and an effort menu: Quick (no reasoning, short answers, few steps), Normal, Deep (the model reasons before it answers, about 3 times slower, the page says "Thinking..."). The effort is remembered for each page.
  - A model is chosen for you when none is chosen yet (Qwen3.5 4B first).
  - Not code-signed (Windows SmartScreen may warn).

v1.10.0 (2026-11-15): Local first: the model on this PC does the work, searches the web, and the installer downloads it
  - New: the model on this PC is now the first choice and the default of both AI pages. On the Agentic AI page it works as a real agent in the folder you choose: it looks at the files (list, read, search) and, only if you allow "can edit files", writes files (a file that is replaced is first saved in .drivevault-backup). It cannot run programs or delete anything, and a path can never leave the folder.
  - New: the AI can search the web (DuckDuckGo) and open a page to read it, on both pages, when "Web" is on (switch in the AI settings and a chip under the message box; on by default, switch it off to stay offline). Only the search words and the address of a page go out; your files and conversation do not. Pages on this computer or the local network are never opened.
  - New: the installer downloads the AI model (Qwen3.5-4B, about 2.7 GB, Apache-2.0) while it installs. It is a task on the "Select additional tasks" page, on by default: clear it to skip. The file is checked against a fixed SHA-256; a failed or cancelled download installs the program without the model and says so. Silent installs (the programs' installers run this setup silently) never download. Models downloaded later are kept when the program is uninstalled.
  - New in the catalogue: Typhoon 2.5 Qwen3 4B (Thai-focused, official GGUF). It has not been tested in this program; Qwen3.5 4B is the tested default.
  - Limits: web search uses DuckDuckGo's HTML page, which may change or refuse; a few sites whose certificate chain is incomplete cannot be opened. The web and file tools work with the model on this PC only (not with an API key or Claude Code / Codex, which have their own tools).
  - Not code-signed (Windows SmartScreen may warn).

v1.9.0 (2026-11-15): The local AI engine is in the installer
  - New: the installer now carries the llama.cpp engine (Vulkan build b12170, MIT; about 100 MB) in the "ai\llama" folder, so a model on this PC works without installing PDF Pro. Every file is checked against its audited SHA-256 when the installer is built. No model is included: you still download one in the AI settings, only when you press Download.
  - The licences of llama.cpp, its OpenMP runtime and the Qwen3.5 models are in the "licenses" folder.
  - Not code-signed (Windows SmartScreen may warn).

v1.8.0 (2026-11-15): The AI pages work
  - New: the AI Q&A and Agentic AI pages talk to a real AI. Each page has its own settings (button "AI settings") where you choose one of:
    * a model on this PC: llama.cpp with a GGUF model. Download one of the catalogue (Qwen3.5 0.8B / 2B / 4B / 9B from Hugging Face) or paste a huggingface.co link to a .gguf file. Downloads start only when you press Download and are checked against a fixed size and SHA-256; Check on a pasted link only asks Hugging Face for its size and checksum. Everything stays on this computer.
    * an API: OpenAI style (OpenAI, OpenRouter, Ollama, LM Studio ...) or Anthropic, with your own key. The key is kept encrypted for your Windows user and is sent only to the address you set (https, or this computer).
    * Claude Code or Codex: the easy way - the program you already have and are signed in to. Master Pro starts it with fixed options and gives it the question on its standard input; it never sees your password. The agent page works in the folder you choose: read only, or "can edit files" if you allow it; it cannot run commands.
  - Answers stream in as they are written, can be stopped, and are kept as conversations (list on the left, saved in %LOCALAPPDATA%\DriveVault\MasterPro\ai). A failure is shown in the conversation in words, with what the service said.
  - Limits: Codex is tested with a stand-in only; a signed-in Claude Code session must be valid (the program says "Failed to authenticate" otherwise: sign in again with /login).
  - Not code-signed (Windows SmartScreen may warn).

v1.7.0 (2026-11-15): The AI Q&A and Agentic AI pages

  - **No AI is connected yet.** The pages say "Not connected": the message box only keeps what you type in the window (nothing is sent anywhere), and the buttons that need an AI (New conversation / New task, Send) are switched off. There are no made-up answers.

v1.1.0 (2026-11-07)
  New
  - "Check for updates" button: asks the GitHub Releases of newzydev/drivevault-suite which version of each program exists. It runs only when you press the button;
    nothing is checked or downloaded in the background.
  - "Download version X and update / install": downloads the setup file from the official release address, compares its SHA-256 with the release's .sha256 file,
    checks that it is the right DriveVault program and version, then runs it like any other setup file. The downloaded file is deleted after a successful run.
  Changed
  - The licence text (EULA) says that "Check for updates" contacts GitHub.
  - Fixed: the Thai product section (6) of the licence text was shown garbled; the licence generator script is now saved with a byte order mark.
  Notes
  - (1.1.0 only) Master Pro did not update itself; since 1.2.0 it does.
  - GitHub limits anonymous requests (60 per hour per connection): if the check says so, try again later.

Known limitations
  - Installers are not code-signed (a certificate has to be bought). Windows may show "Windows protected your PC": choose "More info" and then "Run anyway".
    The SHA-256 check above protects against a damaged or swapped download, not against a compromised release.
  - Not tested on a clean machine / VM.

v1.0.0
  - First release: lists, opens, installs, updates (from setup files on this PC) and uninstalls DriveVault programs; installed automatically by every program installer.
