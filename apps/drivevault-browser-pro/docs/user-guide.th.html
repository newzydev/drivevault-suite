DriveVault Browser Pro - คู่มือการใช้งาน (รุ่น 1.3.0)

เว็บเบราว์เซอร์สำหรับ Windows ที่ใช้ Chromium (Qt WebEngine) มีตัวบล็อกโฆษณา ภาพซ้อนภาพ และตัวบันทึกวิดีโอ ทุกอย่างอยู่ในเครื่องของคุณ ไม่มีบัญชี ไม่ซิงก์ และไม่ส่งข้อมูลการใช้งานให้ DriveVault

โปรไฟล์ในเครื่อง

เมื่อเปิดครั้งแรก เบราว์เซอร์จะแสดงแท็บหน้าแรก ให้เลือกเข้าสู่ระบบด้วย Google หรือเข้าแบบผู้เข้าชมบนหน้าเว็บ เข้าสู่ระบบผ่านเบราว์เซอร์หลัก แล้วตั้ง PIN 6 หลัก กดโปรไฟล์ในเมนูสามจุดเพื่อกำหนดเวลาล็อกอัตโนมัติหรือออกจากระบบ ข้อมูลของแต่ละบัญชีเก็บแยกกันในเครื่อง

การท่องเว็บ

ลากแท็บเพื่อจัดลำดับ กด Ctrl+Shift+A เพื่อค้นหาแท็บที่เปิดอยู่ หรือ Ctrl+P เพื่อพิมพ์หน้าเว็บ เมนูหน้าเว็บเปิดโหมดอ่านและบันทึกส่วนที่มองเห็นเป็น PNG ได้ เลื่อนเมาส์เหนือทางลัดเพื่อเปิดเมนูสามจุดสำหรับแก้ไขหรือลบ ใช้การตั้งค่าความเป็นส่วนตัวเพื่อล้างคุกกี้หรือรีเซ็ตสิทธิ์รายเว็บไซต์ และใช้แผงบุ๊กมาร์กเพื่อนำเข้าไฟล์ Bookmarks จากโปรไฟล์ Chrome

แท็บ (เปิดใหม่ ปิด ทำซ้ำ ปักหมุด เปิดแท็บที่ปิดไปคืน) แถบที่อยู่ (ค้นด้วย Google เป็นค่าเริ่มต้นเมื่อพิมพ์คำค้น) บุ๊กมาร์ก (นำเข้า / ส่งออกเป็น HTML) ประวัติ ดาวน์โหลด ค้นหาในหน้า (Ctrl+F) ซูมแยกตามเว็บไซต์ เต็มจอ บันทึกเป็น PDF ดูต้นฉบับ เครื่องมือนักพัฒนา และหน้าต่างส่วนตัวที่ไม่เก็บอะไรลงดิสก์ เว็บไซต์ที่ขอใช้กล้อง ไมโครโฟน ตำแหน่ง ฯลฯ จะถามคุณก่อน การแจ้งเตือนถูกปฏิเสธไว้ก่อน

ใช้ปุ่ม ไทย / EN บนแถบหัวหน้าต่างเพื่อเปลี่ยนภาษาของโปรแกรม กดรูปเฟืองเพื่อเปิดการตั้งค่า หรือกดสามจุดเพื่อเปิดรายการคำสั่งใต้แถบเครื่องมือ ปุ่มรูปบ้านเปิด Google เป็นค่าเริ่มต้น และเปลี่ยนปลายทางได้ในแผงตั้งค่า

หน้าต่างหลักจะเปิดกลับมาด้วยขนาดและตำแหน่งเดิม หรือเปิดแบบขยายเต็มหน้าจอตามที่ใช้ล่าสุด ดับเบิลคลิกแถบชื่อเพื่อขยายหรือคืนขนาด กด F11 เพื่อเข้าและออกจากโหมดเต็มจอของเบราว์เซอร์

หน้าแท็บใหม่มีภาพพื้นหลังในตัวและสองแท็บ ทางลัดมี Google เป็นค่าเริ่มต้นและจัดการแยกจากบุ๊กมาร์ก ส่วนเข้าบ่อยสุดจะแสดงเว็บจากประวัติ กดเพิ่มทางลัดเพื่อบันทึกชื่อและ URL ของเว็บ โปรแกรมใช้ไอคอนจากเว็บที่เคยเปิดและแสดงตัวอักษรเมื่อไม่มีไอคอน ใช้แสดงน้อยลงเพื่อซ่อนรายการเว็บ แล้วกดแสดงเพิ่มเติมเพื่อเปิดอีกครั้ง คลิกขวาบนพื้นที่ว่างของหน้าแท็บใหม่หรือเว็บเพจเพื่อเปิดเมนูคำสั่งธีมมืด

โล่ (ตัวบล็อกโฆษณา)

ปุ่มโล่แสดงจำนวนคำขอที่ถูกหยุดในหน้านั้น โปรแกรมมีลิสต์ 4 รายการ (EasyList, EasyPrivacy, Fanboy's Social Blocking List, Fanboy's Annoyance List) มาด้วยเป็นสำเนา แสดงวันที่ในแผงโล่ ปุ่ม อัปเดตลิสต์ตัวกรอง ดาวน์โหลดรุ่นใหม่จาก easylist.to เฉพาะเมื่อคุณกดเท่านั้น เปิด/ปิดแต่ละลิสต์ การซ่อนองค์ประกอบในหน้า และสคริปต์ป้องกันได้ และหยุดโล่เฉพาะเว็บไซต์ที่ใช้ไม่ได้

ป้องกันหน้าที่ตรวจจับตัวบล็อกโฆษณา (เปิดไว้ก่อน) ซ่อนกำแพง "ปิดตัวบล็อกโฆษณา" และตอบสคริปต์ตรวจจับทั่วไป ทดสอบกับหน้าทดลองแล้ว ไม่ใช่การรับประกัน: เว็บไซต์ที่ตรวจที่เซิร์ฟเวอร์ของตัวเอง หรือซ่อนเนื้อหาจนกว่าจะแสดงโฆษณา อาจยังใช้ไม่ได้

ภาพซ้อนภาพ

ปุ่มภาพซ้อนภาพ (หรือ Alt+P) ย้ายแท็บไปอยู่ในหน้าต่างเล็กที่อยู่บนสุดเสมอ วิดีโอเต็มหน้าต่างและเล่นต่อ ใช้กับวิดีโอในหน้าหลักและเฟรมที่มีต้นทางเดียวกับหน้าหลัก

บันทึกวิดีโอ

จะมีปุ่มพร้อมตัวเลขเมื่อหน้านั้นโหลดไฟล์วิดีโอ/เสียง หรือรายการเล่น HLS / DASH ไฟล์จะถูกบันทึกตามที่เป็น สตรีม HLS / DASH จะถูกรวมเป็นไฟล์ .mp4 ไฟล์เดียวโดยไม่เข้ารหัสใหม่ด้วย FFmpeg (ติดตั้งมากับโปรแกรม) ดูความคืบหน้าในแผงดาวน์โหลด

บันทึกเฉพาะสิ่งที่คุณมีสิทธิ์เก็บ สตรีมที่มีการป้องกันการคัดลอก (DRM) จะถูกปฏิเสธ และไม่เสนอการบันทึกจาก YouTube และบริการสตรีมแบบสมัครสมาชิกหรือเพลง เพราะข้อกำหนดของเขาห้ามไว้

ข้อจำกัดของรุ่นนี้

  • ยังไม่มีส่วนขยาย (Qt 6.8 โหลดส่วนขยายไม่ได้) และไม่มีการล็อกอินหรือซิงก์ Google
  • เอนจินไม่มีตัวถอดรหัส H.264 / AAC วิดีโอบางรายการจึงเล่นไม่ได้
  • โปรแกรมไม่ตั้งตัวเองเป็นเบราว์เซอร์เริ่มต้น หากต้องการให้ตั้งเองใน การตั้งค่า Windows
  • ตัวติดตั้งยังไม่ได้เซ็นรหัส (code signing)

ข้อมูลของคุณ

ประวัติ บุ๊กมาร์ก การตั้งค่า คุกกี้ และลิสต์ที่อัปเดต อยู่ที่ %LOCALAPPDATA%\DriveVault\BrowserPro การถอนการติดตั้งไม่ลบข้อมูลเหล่านี้หรือวิดีโอที่บันทึกไว้
