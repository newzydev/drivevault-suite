v0.3.0 (2026-11-19): Inside the page (Phase 3). Element hiding of the filter lists (generic names found by watching the page, specific rules, injected styles, exceptions, $generichide / $elemhide), 22 scriptlets written for this program (set-constant, abort-on-property-read / write, abort-current-script, no-fetch-if, no-xhr-if, timers, json-prune, remove-attr / class, storage and cookie values ...) that run before the scripts of the page, and stand-in files for blocked ad / analytics libraries ($redirect= and a built-in table) so that pages do not break. New switch "hide page elements and run protection scripts". Not implemented: the defence against pages that detect ad blockers (Phase 4), procedural selectors, hiding inside frames. Not released: there is no installer.
v0.2.0 (2026-11-19): Ad blocker engine (Phase 2). Network filters of the Adblock Plus / uBlock Origin syntax (host, path, wildcard, anchors, $script / $image / $third-party / $domain / $important and exceptions) are read from filter lists and stop requests before they leave the PC, in normal and private windows. Shield button with the count of the page, pause per site, switch per list, an Update button (downloads only when pressed). No filter list is shipped or downloaded yet. Page elements, scriptlets and the anti-adblock defence are not implemented yet. Not released: there is no installer.
v0.1.0 (2026-11-19): First build of DriveVault Browser Pro (Phase 1, the browser shell). Tabs, address bar with suggestions, bookmarks (HTML import / export), history, downloads, find in page,
zoom per site, private window, website permissions, save as PDF, view source, developer tools, Thai + English. Ad blocking is not implemented yet. Not released: there is no installer.
