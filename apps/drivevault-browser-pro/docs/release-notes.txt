v1.0.0 (2026-11-19): First stable release. Includes the redesigned new-tab workspace with site icons and shortcuts, persistent browsing in normal windows, Thai and English settings, ad blocking with bundled lists, picture in picture, and saving supported media. Extensions remain on hold. H.264 / AAC playback and the remaining planned browser features are deferred. Ad-block detection protection has been verified on lab pages. The installer is unsigned.

The default Google shortcut includes its official favicon. Explicitly enable persistent storage for the normal profile so cached website icons survive restart. The installer is unsigned.

v0.6.0 (2026-11-19): Installer and Master Pro (Phase 6). New setup DriveVault-Browser-Pro-Setup-x64.exe (Qt WebEngine / Chromium, FFmpeg for saving HLS / DASH streams, a snapshot of the four filter lists EasyList, EasyPrivacy, Fanboy's Social and Annoyance lists - shown with its date, the Update button still replaces them; downloads Master Pro first like the other installers; does not make the program the default browser). The program is listed in Master Pro (cyan card). Release gates: clean-machine imports, licence audit (every file has an owner, FFmpeg LGPL only, list files unchanged), notices, user guides (English / Thai). The date of a shipped list is now read from the list's own .meta.json. Beta: no extensions (Qt 6.8 has no extension support), no Google sign-in or sync (cancelled), the defence against ad block detection has only been shown on lab pages, not on a real ad block wall; H.264 / AAC videos do not play (Chromium without proprietary codecs). The installer is unsigned and was built but NOT install-tested; no Release is published.
v0.5.0 (2026-11-19): Picture in picture and saving videos (Phase 5). Picture in picture: the engine's own one is off, so the tab moves into a small always-on-top window and the video of the page fills it and keeps playing (button, Alt+P; videos in the main frame only). Saving videos: a button with a count appears when a page loaded a video / audio file or an HLS / DASH playlist; a file is saved by the program itself, an HLS stream is copied into an .mp4 with FFmpeg (FFmpeg is not shipped yet, so streams work only where FFmpeg is installed); the downloads panel shows the progress. YouTube and subscription streaming sites are never offered, DRM-protected playlists are refused, no log-in cookies are used. Tested with lab pages and local servers (tst_media 29 checks, picture in picture 14 checks, saving 10 checks in the program); not tested on real websites. Not released: there is no installer.
v0.4.1 (2026-11-19): Fixes found by the first test on real websites (20 sites, see docs/anti-adblock-results.md). The program no longer crashes (or is much less likely to) when it is ended while a heavy page is still loading: the tab model is destroyed after the pages, the pages are stopped when the window closes, a closed window is destroyed 2 s later. Sounds are muted when DV_NO_AUDIO is set (the variable was ignored before). Diagnostics --survey / --wait for tests on real sites. Result of that test: the blocker kept 96 - 102 % of the page text on 15 of 16 loadable sites, stopped 3 - 79 requests per page and removed most advertising frames; no site showed an ad block wall, so the defence is still shown only on lab pages. Not released: there is no installer.
v0.4.0 (2026-11-19): Defence against pages that detect ad blockers (Phase 4), new switch "Defend against pages that detect ad blockers" (on by default, works without any filter list). Empty bait boxes are never hidden; detector libraries (FuckAdBlock / BlockAdBlock style) are answered "no ad blocker"; walls that say "turn off your ad blocker" are hidden and scrolling is released; fetch / XHR to known ad addresses and pictures from blocked addresses now succeed instead of failing. Tested with lab pages on this computer (each detector with the defence on and off, see docs/anti-adblock-results.md); NOT tested on real websites, and pages that check on their server or keep their content hidden until an ad was shown can still refuse to work. Not released: there is no installer.
v0.3.0 (2026-11-19): Inside the page (Phase 3). Element hiding of the filter lists (generic names found by watching the page, specific rules, injected styles, exceptions, $generichide / $elemhide), 22 scriptlets written for this program (set-constant, abort-on-property-read / write, abort-current-script, no-fetch-if, no-xhr-if, timers, json-prune, remove-attr / class, storage and cookie values ...) that run before the scripts of the page, and stand-in files for blocked ad / analytics libraries ($redirect= and a built-in table) so that pages do not break. New switch "hide page elements and run protection scripts". Not implemented: the defence against pages that detect ad blockers (Phase 4), procedural selectors, hiding inside frames. Not released: there is no installer.
v0.2.0 (2026-11-19): Ad blocker engine (Phase 2). Network filters of the Adblock Plus / uBlock Origin syntax (host, path, wildcard, anchors, $script / $image / $third-party / $domain / $important and exceptions) are read from filter lists and stop requests before they leave the PC, in normal and private windows. Shield button with the count of the page, pause per site, switch per list, an Update button (downloads only when pressed). No filter list is shipped or downloaded yet. Page elements, scriptlets and the anti-adblock defence are not implemented yet. Not released: there is no installer.
